# 智卷云（zujuan-platform）—— 题库与智能组卷平台

> 英文品牌 **ExamForge**（代码标识 examforge-*，已全面去拼音化）｜中文名"智卷云"：对标并超越组卷网、菁优网的全学段（小学→考研）题库与组卷平台。
> 三大差异化：**内容全结构化**（LaTeX 公式 + 白底统一图形）、**AI 原生**（组卷/出题/讲题/审校）、**下载即所得**（专业排版导出）。
> 设计容量：注册用户 **8000 万+**，题目 **9000 万+**（容量 v2 权威口径与端形态定稿见 [docs/28](docs/28-端形态定稿与服务器架构设计.md)）。

## 🏢 企业级全栈工程（code/enterprise，已落地）

Spring Cloud 微服务族 ×8（gateway/user/question/paper/admin/trade/practice/ai）+ 双前端（教师端/超管端 Vue3）+ docker-compose + CI；`mvn -B test` 11/11 模块全绿、双前端构建通过。架构与拆分见 docs/03/07/13，进度实况见 **[docs/22-功能完成进度任务书.md](docs/22-功能完成进度任务书.md)**。
