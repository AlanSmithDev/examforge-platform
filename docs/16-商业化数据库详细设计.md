## 1. ER 总览（交易域）

```
member_plan ──< trade_order >── payment_log
     │              │  │
     │              │  └── coupon_id ──> user_coupon >── coupon_template
     │              └── order_no ──< point_log（成对流水）
points_package（点数充值套餐 SKU）
point_account 1:1 user；point_account ──< point_log
download_record（判价与扣费依据）；sign_in_log / invite_record（营销）
```

- 会员状态不建独立 member 表：**`users.member_until` 即会员到期时间**（MVP 与企业版一致口径；企业版 `member` 表为 profile 扩展，档位冗余在 order 履约时回写 `users.plan_code`）。
- 金额/点数单位：**一律整数分（cents）与整数点（point）**，禁止浮点。100 点 = 1 元。

## 2. 会员与套餐（REQ-M）

```sql
-- MySQL
CREATE TABLE `member_plan` (
  `id`             INT AUTO_INCREMENT PRIMARY KEY,
  `code`           VARCHAR(32)  NOT NULL COMMENT '档位编码：FREE/TEACHER_PRO/SINGLE/STUDENT/NEWBIE_7D',
  `name`           VARCHAR(64)  NOT NULL,
  `price_cents`    INT          NOT NULL DEFAULT 0 COMMENT '售价（分），0=免费/内部档',
  `duration_days`  INT          NOT NULL DEFAULT 30,
  `subject_id`     INT          NULL COMMENT 'SINGLE 单科档关联学科，NULL=全科',
  `benefits`       JSON         NULL COMMENT '权益清单 ["下载不限次","AI 50次/日"]',
  `purchasable`    TINYINT      NOT NULL DEFAULT 1 COMMENT '0=不可售（体验/内部档）',
  `sort`           INT NOT NULL DEFAULT 0, `status` TINYINT NOT NULL DEFAULT 1,
  UNIQUE KEY `uk_code` (`code`)
) COMMENT '会员档位（后台可配）';

CREATE TABLE `points_package` (
  `id`            INT AUTO_INCREMENT PRIMARY KEY,
  `points`        INT NOT NULL COMMENT '到账点数（含赠送）',
  `bonus_points`  INT NOT NULL DEFAULT 0 COMMENT '其中赠送点数（fuint 充X送Y 模式）',
  `price_cents`   INT NOT NULL,
  `label`         VARCHAR(64) NULL, `sort` INT NOT NULL DEFAULT 0, `status` TINYINT NOT NULL DEFAULT 1
) COMMENT '点数充值套餐';
```

**会员到期叠加公式（M-2）**：`member_until = member_until > now ? member_until + duration : now + duration`；`NEWBIE_7D` 为 7 日体验档（purchasable=0，注册事务内发放）。会员失效（`member_until < now`）后点数余额保留（M-4，惰性判定 + 每日扫描双保险）。

## 3. 点数账户与流水（REQ-P）

```sql
CREATE TABLE `point_account` (
  `user_id`         BIGINT PRIMARY KEY,
  `balance`         INT NOT NULL DEFAULT 0 COMMENT '可用点数，不可透支',
  `total_recharge`  INT NOT NULL DEFAULT 0 COMMENT '累计充值点数（统计口径，不含赠送）',
  `version`         INT NOT NULL DEFAULT 0 COMMENT '乐观锁',
  `updated_at`      DATETIME
) COMMENT '点数账户';

CREATE TABLE `point_log` (
  `id`             BIGINT AUTO_INCREMENT PRIMARY KEY,
  `user_id`        BIGINT NOT NULL,
  `order_no`       VARCHAR(64) NULL COMMENT '关联订单（退款去重靠流水）',
  `biz_type`       VARCHAR(24) NOT NULL COMMENT 'RECHARGE/RECHARGE_BONUS/CONSUME/REFUND/GIFT_NEWBIE/GIFT_INVITE/SIGN/ERROR_REWARD/ADMIN_ADJUST',
  `delta`          INT NOT NULL COMMENT '变动点数，正增负减',
  `balance_after`  INT NOT NULL COMMENT '变动后余额（lilishop 双值流水，排查并发丢失）',
  `note`           VARCHAR(255) NULL,
  `created_at`     DATETIME NOT NULL,
  KEY `idx_user_time` (`user_id`, `id` DESC),
  KEY `idx_order` (`order_no`)
) COMMENT '点数流水（账户每次变动必写一笔，对账链路 balance_after 连续）';
```

**扣减原子性（P-1）**：SQLite 单写事务内 `UPDATE point_account SET balance = balance - ?, version = version + 1 WHERE user_id = ? AND balance >= ?`，`changes === 0` 即余额不足返回 `42900`；企业版同语句（MySQL 行锁等价）。**禁止"先 SELECT 再 UPDATE"两段式**。

## 4. 优惠券（REQ-C，模板-用户券两层）

```sql
CREATE TABLE `coupon_template` (
  `id`               INT AUTO_INCREMENT PRIMARY KEY,
  `code`             VARCHAR(32) NOT NULL COMMENT '模板编码',
  `name`             VARCHAR(64) NOT NULL,
  `type`             VARCHAR(16) NOT NULL COMMENT 'FULL_REDUCTION 满减 / DISCOUNT 折扣 / POINTS 点数券',
  `amount_cents`     INT NOT NULL DEFAULT 0 COMMENT '满减面额（分）或点数券点数',
  `discount_rate`    INT NOT NULL DEFAULT 0 COMMENT '折扣率百分数，85=8.5折',
  `max_discount_cents` INT NOT NULL DEFAULT 0 COMMENT '折扣封顶（分），0=不封顶',
  `threshold_cents`  INT NOT NULL DEFAULT 0 COMMENT '使用门槛（订单实付≥此值），0=无门槛',
  `total`            INT NOT NULL DEFAULT 0 COMMENT '发放总量，0=不限',
  `claimed`          INT NOT NULL DEFAULT 0 COMMENT '已领数量（条件 UPDATE 原子自增）',
  `per_limit`        INT NOT NULL DEFAULT 1 COMMENT '每人限领，0=不限（按全状态计数）',
  `claim_start`      DATETIME NULL, `claim_end` DATETIME NULL COMMENT '领取窗口',
  `valid_days`       INT NULL COMMENT '动态有效期：领后 N 天',
  `fixed_end`        DATETIME NULL COMMENT '固定有效期截止',
  `scope`            VARCHAR(16) NOT NULL DEFAULT 'ALL' COMMENT 'ALL 全部 SKU / MEMBER 仅会员SKU / POINTS 仅充值SKU',
  `status`           TINYINT NOT NULL DEFAULT 1 COMMENT '1 上架 0 下架 2 作废（连带用户券 CLOSED）',
  `note`             VARCHAR(255) NULL, `created_at` DATETIME NOT NULL,
  UNIQUE KEY `uk_code` (`code`)
) COMMENT '券模板';

CREATE TABLE `user_coupon` (
  `id`            BIGINT AUTO_INCREMENT PRIMARY KEY,
  `template_id`   INT NOT NULL,
  `user_id`       BIGINT NOT NULL,
  `status`        VARCHAR(12) NOT NULL DEFAULT 'UNUSED' COMMENT 'UNUSED 未用 / FROZEN 下单占用 / USED 已核销 / EXPIRED 已过期 / CLOSED 模板作废',
  `snapshot`      JSON NOT NULL COMMENT '发券瞬间模板快照：{type,amountCents,discountRate,maxDiscountCents,thresholdCents,scope,name}',
  `source`        VARCHAR(24) NOT NULL DEFAULT 'CLAIM' COMMENT 'CLAIM 领取 / GIFT_NEWBIE / GIFT_INVITE / ADMIN_SEND',
  `used_order_no` VARCHAR(64) NULL COMMENT '核销/占用所在订单',
  `claimed_at`    DATETIME NOT NULL, `used_at` DATETIME NULL, `expire_at` DATETIME NOT NULL,
  KEY `idx_user_status` (`user_id`, `status`), KEY `idx_expire` (`status`, `expire_at`),
  KEY `idx_template` (`template_id`)
) COMMENT '用户券（快照冗余，不回查模板）';
```

**关键规则（v1.1 定稿，覆盖 14 号 C 节）**：
- **C-4' 生命周期**：`UNUSED → FROZEN（下单占用，记 used_order_no）→ USED（支付成功核销）`；`FROZEN → UNUSED（关单/退款返还，仅当未过期）`；`UNUSED/FROZEN → EXPIRED`（到期；过期由**每日任务+查询惰性**双保险触发）。作废模板连带全部 `→ CLOSED`。
- **C-3' 防超发**：领取 = 同事务两条条件 UPDATE：`UPDATE coupon_template SET claimed=claimed+1 WHERE id=? AND status=1 AND (total=0 OR claimed<total) AND (claim_start IS NULL OR claim_start<=now) AND (claim_end IS NULL OR claim_end>=now)` 影响行数=0 → 拒绝；每人限领按 `COUNT(*)` 全状态统计（lilishop 口径）。
- **C-6' 有效期**：`expire_at = valid_days ? claimed_at + valid_days 天 : fixed_end`，发券瞬间计算并落快照（DYNAMICTIME 模式）。
- **C-4'' 核销**：支付履约事务内 `UPDATE user_coupon SET status='USED', used_at=now WHERE id=? AND status='FROZEN' AND used_order_no=?` 影响行数=0 → 整单回滚（防同券两单）。
- **C-5' 返还**：退款/关单事务内 `UPDATE user_coupon SET status='UNUSED', used_order_no=NULL WHERE used_order_no=? AND status IN ('FROZEN','USED') AND expire_at > now`（过期不返还，CRMEB 口径）。

## 5. 订单与支付（REQ-O）

```sql
CREATE TABLE `trade_order` (
  `id`                BIGINT AUTO_INCREMENT PRIMARY KEY,
  `order_no`          VARCHAR(64) NOT NULL COMMENT 'ZJ+yyMMddHHmmss+6位随机',
  `user_id`           BIGINT NOT NULL,
  `sku_type`          VARCHAR(12) NOT NULL COMMENT 'MEMBER / POINTS / PAPER',
  `sku_ref`           VARCHAR(32) NOT NULL COMMENT 'plan.code 或 package.id 或 paper.id',
  `title`             VARCHAR(128) NOT NULL,
  `origin_cents`      INT NOT NULL COMMENT '原价（分）',
  `discount_cents`    INT NOT NULL DEFAULT 0 COMMENT '券抵扣（分）',
  `pay_cents`         INT NOT NULL COMMENT '实付 = origin - discount，≥0',
  `coupon_id`         BIGINT NULL,
  -- 三状态分离（lilishop 口径），禁止单一 status 承载
  `status`            VARCHAR(12) NOT NULL DEFAULT 'CREATED' COMMENT 'CREATED/PAID/CLOSED/REFUNDED',
  `pay_status`        VARCHAR(12) NOT NULL DEFAULT 'UNPAID' COMMENT 'UNPAID/PAID',
  `refund_status`     VARCHAR(12) NOT NULL DEFAULT 'NONE' COMMENT 'NONE/REFUNDING/REFUNDED',
  `pay_channel`       VARCHAR(12) NULL COMMENT 'MOCK/WECHAT/ALIPAY',
  `idempotency_key`   VARCHAR(64) NULL,
  `fulfil_json`       JSON NULL COMMENT '履约快照：{daysAdded,pointsCredited,bonusPoints,couponId}',
  `paid_at` DATETIME NULL, `closed_at` DATETIME NULL, `expire_at` DATETIME NOT NULL COMMENT 'CREATED+30min',
  `created_at`        DATETIME NOT NULL,
  UNIQUE KEY `uk_order_no` (`order_no`),
  UNIQUE KEY `uk_idem` (`user_id`, `idempotency_key`),
  KEY `idx_user` (`user_id`, `id` DESC), KEY `idx_timeout` (`status`, `expire_at`)
) COMMENT '交易订单（幂等键用户内唯一，重复请求返回原单）';

CREATE TABLE `payment_log` (
  `id`           BIGINT AUTO_INCREMENT PRIMARY KEY,
  `order_no`     VARCHAR(64) NOT NULL,
  `channel`      VARCHAR(12) NOT NULL,
  `callback_id`  VARCHAR(64) NOT NULL COMMENT '渠道回调流水号，唯一索引防重放',
  `amount_cents` INT NOT NULL, `result` VARCHAR(12) NOT NULL COMMENT 'ACCEPTED/DUPLICATED/REJECTED',
  `payload`      JSON NULL COMMENT '验签前的原始报文（对账与取证）',
  `created_at`   DATETIME NOT NULL,
  UNIQUE KEY `uk_callback` (`channel`, `callback_id`),
  KEY `idx_order` (`order_no`)
) COMMENT '支付回调流水（先落流水再履约；DUPLICATED 直接返回首次结果）';
```

**O-3' 状态机（合法跃迁表）**：

| from → to | 触发 | 校验 |
|---|---|---|
| CREATED → PAID | 支付回调 | `pay_cents` 与回调金额一致；履约事务见 O-5 |
| CREATED → CLOSED | 超时任务 / 用户关单 / 退款前检查 | 仅 CREATED 可关；关单事务内返还 FROZEN 券 |
| PAID → REFUNDED | 超管退款 | 回滚顺序见 §8；写 REFUND 流水 |
| 其余跃迁 | — | 一律拒绝（代码内显式白名单，非法跃迁抛 `40001`） |

## 6. 下载计费（REQ-D）

```sql
CREATE TABLE `download_record` (
  `id`             BIGINT AUTO_INCREMENT PRIMARY KEY,
  `user_id`        BIGINT NOT NULL,
  `paper_id`       BIGINT NULL, `paper_hash` VARCHAR(64) NOT NULL COMMENT '题目ID有序串 SHA-256',
  `question_count` INT NOT NULL,
  `charge_mode`    VARCHAR(12) NOT NULL COMMENT 'FREE_REPEAT/FREE_QUOTA/MEMBER/POINTS',
  `points_charged` INT NOT NULL DEFAULT 0,
  `order_no`       VARCHAR(64) NULL COMMENT '点数不足时引导下单的 PAPER 单',
  `created_at`     DATETIME NOT NULL,
  KEY `idx_user_hash` (`user_id`, `paper_hash`, `created_at`)
) COMMENT '下载记录：30天重复下载免计费（D-4）+ 免费额度依据';
```

**计费档位（P-3，对标组卷网并降 50%）**：1-10 题=100 点 / 11-20 题=200 点 / 21-50 题=400 点 / 51-100 题=600 点（>100 每满 50 题 +100）。判价顺序 **D-1**：30 天内重复下载 → 会员有效 → 免费额度 3 次/日（settings 键 `free_downloads_per_day`）→ 点数扣减。**扣费在导出成功之后**（D-2），失败不计费。

## 7. 营销（REQ-K）

```sql
CREATE TABLE `sign_in_log` (
  `id` BIGINT AUTO_INCREMENT PRIMARY KEY, `user_id` BIGINT NOT NULL,
  `sign_date` DATE NOT NULL, `continuous` INT NOT NULL COMMENT '连续天数（昨日未签清零，CRMEB 口径）',

  UNIQUE KEY `uk_user_date` (`user_id`, `sign_date`)  -- 防刷：一日一签靠唯一索引

CREATE TABLE `invite_record` (
  `id` BIGINT AUTO_INCREMENT PRIMARY KEY,
  `inviter_id` BIGINT NOT NULL, `invitee_id` BIGINT NOT NULL,
  `points_awarded` INT NOT NULL DEFAULT 20,
  `created_at` DATETIME NOT NULL,
```

用户表增量：`ALTER TABLE users ADD COLUMN invite_code VARCHAR(12) NULL UNIQUE, ADD COLUMN inviter_id BIGINT NULL`；新人礼包（K-1）在注册事务内一次性发放：NEWBIE_7D 会员 + 10 点（`GIFT_NEWBIE` 流水 + user_coupon 新人券），靠注册幂等保证不重复。

## 8. 退款回滚顺序（强约束，CRMEB 事故教训）

同一事务内固定顺序执行，任一步失败整体回滚：
1. 订单 `PAID → REFUNDED`（`refund_status='REFUNDED'`，非法跃迁拒绝）；
2. **券返还**：按 `used_order_no` 返还（§4 C-5'）；
3. **点数返还/回收**：按 `point_log.order_no` 查本次履约流水——已存在 `REFUND` 流水则拒绝（**流水去重防重复返还**）；回收 `fulfil_json.pointsCredited`（余额不足回收时钳位至 0，差额记 `note`，不允许负余额）；
4. **会员回收**：`member_until -= fulfil_json.daysAdded`（不早于当前时间，即已享受天数不追讨）；
5. 审计日志（action=`TRADE_REFUND`）。

## 9. MVP（SQLite）映射与种子

| 企业版 | SQLite 落地（code/app/server/db.js） | 差异说明 |
|---|---|---|
| BIGINT/JSON/DATETIME | INTEGER/TEXT(json 字符串)/TEXT(ISO 本地时间) | JSON 读取时 parse，写入前 stringify |
| 自增主键 | INTEGER PRIMARY KEY AUTOINCREMENT | 一致 |
| 唯一索引 | UNIQUE 建表内联 | 一致；`uk_idem` 同 |
| 条件 UPDATE 原子扣减 | better-sqlite3 事务 + `.changes` 判断 | 单写无并发窗口，语义等价 |

**种子数据**（幂等，仅空库插入）：档位 `FREE(0)/STUDENT(1500分·30天)/TEACHER_PRO(2500分·30天)/SINGLE(3900分·30天·subject=高中数学)/NEWBIE_7D(不可售)`；点数套餐 `50元+5000点(赠500)/100元+10000点(赠1200)/200元+20000点(赠3000)/500元+50000点(赠10000)`；券模板 `NEW10 满减10元(无门槛,100张,领后7天)/TEACHER25 折扣9折(封顶20元,满10元可用,50张,领后30天)/P100 点数券100点(200张,领后15天)`；settings 增键 `free_downloads_per_day=3`、`points_per_yuan=100`。

**数据治理**：trade_order/payment_log/point_log 按财务要求留存 ≥3 年不归档；download_record 90 天冷归档（企业版）；`uk_idem` 冲突时 `SELECT` 原单返回（幂等语义），不做 UPSERT。
