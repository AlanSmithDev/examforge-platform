# 数学公式与图形解决方案（本平台核心差异化能力）

> 版本：v1.0 ｜ 关联：03-架构(figure-svc/render-svc) / 04-数据库(figure 表)
> 要解决的问题：**数学题里的公式与几何图形/函数图像，如何在网页上清晰展示、如何高效录入、如何上传已有图片题、如何打印导出不糊。**
>
> **2026-09-28 策略修订（组卷网实站走查后，与产品决策对齐）**：图形以**截图/图片上传为主渠道**（与组卷网录入方式一致），但把图片质量治理做到位——上传即自动清洗为**纯白底、统一线色、统一 DPI**，展示端统一规范（见 2.4 与第 7 节）。**公式与正文仍然必须结构化为 LaTeX**，这是与竞品"连公式都图片化"的本质区别。Figure DSL 与几何画板降级为 P2 增强通道（渐进数字化）。

---

## 0. 设计总纲：一条原则

> **"结构化存储、一次定义、多端渲染"** —— 公式存 LaTeX，图形存自研 Figure DSL（JSON），图片只作兜底。绝不让图片成为内容的唯一形态（组卷网的教训：解析图片化 → 不可检索、不可编辑、放大模糊、打印发糊）。

题目内容 = 结构化 Block 数组（04 文档 `question_content.blocks`）：
```json
[ {"t":"text","v":"如图，在正方体 "},
  {"t":"latex","v":"ABCD-A_1B_1C_1D_1"},
  {"t":"text","v":" 中，"},{"t":"figure","id":123456789},
  {"t":"text","v":" 求异面直线所成角的余弦值。"} ]
```

## 1. 数学公式方案

| 环节 | 方案 | 理由 |
|---|---|---|
| 存储 | LaTeX（标准子集，自定义语法白名单校验） | 行业通用、可转换一切 |
| 网页渲染-列表 | **服务端预渲染 KaTeX → HTML 片段**，CDN/Redis 缓存 | 列表千题不卡、零客户端计算；字体子集化（KaTeX 字体随 CDN 下发） |
| 网页渲染-详情/编辑 | MathJax v3 按需渲染 | 支持更多宏包语义、可交互 |
| 编辑 | MathLive（可视化公式键盘）+ LaTeX 直输双模式 | 教师不用背 LaTeX |
| 导出 PDF | 已预渲染 HTML → Puppeteer 打印（内置数学字体，矢量输出） | 打印精度=屏幕精度 |
| 导出 Word | LaTeX → MathML → **OMML**（MML2OMML.XSL 转换链），得到 **Word 原生可编辑公式** | 教师拿到卷子还能改题，组卷网做不到 |
| 校验 | LaTeX 语法 lint + 渲染预览截图 diff | 防脏数据上架 |

## 2. 数学图形方案（核心）

### 2.1 Figure DSL v1 —— 图形的"源代码"

图形不存 SVG 也不存图片，存 **JSON DSL**（描述"画什么"，渲染器负责"怎么画"）。收益：一份数据渲染任意分辨率（网页矢量/打印 300dpi）、可参数化改图、AI 可生成、可校验。

```json
{
  "schemaVersion": 1,
  "type": "func_plot",
  "canvas": { "width": 420, "height": 300, "margin": 30 },
  "coords": { "xRange": [-3, 3], "yRange": [-2, 6], "grid": true,
              "axes": true, "ticks": 1, "arrow": true, "labels": ["x","y"] },
  "elements": [
    { "t": "func",   "expr": "x^2/2 + 1", "domain": [-3, 3],
      "style": { "stroke": "#1e66f5", "width": 2 } },
    { "t": "line",   "through": [[-3, 2.5], [3, 2.5]], "dash": true,
      "label": { "text": "y=2.5", "pos": "right" } },
    { "t": "point",  "at": [-1.41, 2], "label": "A" },
    { "t": "shade",  "between": ["x^2/2+1", "y=2.5"], "from": -1.41, "to": 1.41,
      "style": { "fill": "rgba(30,102,245,.15)" } }
  ]
}
```

**DSL 能力集（v1 覆盖高中 95% 图形）**：
| 类别 | 元素 |
|---|---|
| 坐标系 | 直角坐标/极坐标、网格、刻度、箭头、标签 |
| 函数 | 表达式绘图（支持分段函数 `piecewise`）、参数曲线、隐函数（v2） |
| 几何 | 点/线段/直线/射线/圆/弧/多边形/角标记/垂直平行符号/虚线辅助线 |
| 标注 | 文本（LaTeX 公式标注）、长度/角度标注、阴影区域 |
| 立体几何 | 等轴测投影基元：立方体/棱锥/圆柱/球/截面/虚线遮挡（实线-虚线自动遮挡是关键细节） |
| 统计 | 柱状/折线/饼图/频率分布直方图/茎叶图/散点 |

### 2.2 渲染管线

```
Figure DSL(JSON)
   ├─ 前端渲染器(自研,TypeScript, SVG输出)  → 网页展示(矢量,任意缩放不糊)
   └─ 服务端 figure-svc
        ├─ Schema 校验(JSON Schema + 语义校验:表达式可解析/点在坐标系内)
        ├─ SVG 生成(同构渲染核心:同一套几何逻辑编译到 Node 执行) → OSS(immutable URL) → CDN
        └─ 打印位图: SVG → resvg 出 300dpi PNG(打印用,Puppeteer 池兜底)
             └─ Word 导出: PNG 嵌入 + 图题
```
技术选型说明：
- **自研渲染核心**为主（参考 JSXGraph 的几何能力，TypeScript 单代码库前后端同构）。
- JSXGraph（LGPL/MIT）可用于编辑器交互层快速起步；**GeoGebra 商用需向官方申请授权（其许可对竞品类商业产品限制严格），立项即启动商务评估，不作为默认依赖**；Desmos API 同理。
- SVG → PNG 用 resvg（Rust，快、无浏览器依赖），复杂特效回退 Puppeteer 池。

### 2.3 录入三通道（教师"画图"的答案）

**通道 A：内嵌几何画板**（面向几何题）
- 基于自研渲染器 + 交互层：工具栏（点/线/圆/多边形/垂足/中点/角平分线）、智能吸附（端点/交点/格点）、自动标注（点标签、直角符号）。
- 画完自动生成 DSL → 实时预览三端效果。

**通道 B：函数绘图器**（面向函数/导数/三角题）
- 输入表达式（支持 LaTeX/常规式）即绘；分段函数、参数滑块（a、k 拖动看图）、常用模板（指数对数/三角/含绝对值/双曲线抛物线）。

**通道 C：模板库**（效率首选）
- 300+ 高考高频图形模板：立体几何（正方体/长方体/三棱锥/圆柱圆锥/外接球内切球/截面）、统计图表全套、数轴/韦恩图/概率树/单位圆/线性规划可行域/三视图。
- 模板=带参数的 DSL，改参数（棱长/角度/数据）即得新图，10 秒出图。

### 2.4 上传图片题的处理流水线（**P0 主渠道**，存量题源数字化）

```
教师上传扫描卷/截图 (JPG/PNG/PDF)
  → media-svc 图像预处理: 版面分析切题 → OpenCV 裁白边/纠偏/增强对比/去摩尔纹
  → 图形清洗规范（对标组卷网"白底清晰、颜色一致"并超越）:
      ✔ 统一纯白背景 (RGB 255,255,255)，透明/灰底自动转白
      ✔ 统一线条颜色: 深灰 #333（扫描杂色/蓝色圆珠笔迹灰化统一），色块仅保留题目语义色
      ✔ 去水印: 修复式擦除(inpainting)来源站水印与页眉页脚
      ✔ 统一 DPI: 展示 2x retina + 打印 300dpi 双版本
  → OCR 双轨:
      文字+公式识别: Mathpix API(首选,公式识别最准) / 开源兜底 pix2tex、SimpleTex
      手写公式: Mathpix Handwriting / 自研微调模型(P2)
  → 智能转换建议:
      ✔ 图内公式 → 提取为 LaTeX 块(正文数字化,必做)
      ✔ 函数图像 → 尝试反解表达式生成 DSL(识别成功率中,人工确认,可选项)
      ✔ 几何示意图 → 保留清洗后图片(主形态) + 建议"用画板重画"(渐进数字化,不强求)
  → 双存储: 原图(存证) + 清洗版(白底统一,上架用)
  → 展示: CDN 自适应 WebP/AVIF + 懒加载 + 固定宽高占位(防布局抖动) + 悬停放大镜
  → 打印: 300dpi PNG,打印预览强制人工确认
```
- 质量红线：清洗后仍不达标的图片题不允许进入组卷默认池（可标记"图片题"单独筛选）。
- 成本控制：Mathpix 按量采购 + 队列削峰；免费用户录题配额防滥用。

### 2.5 各端渲染效果承诺表

| 端 | 公式 | 图形 | 兜底 |
|---|---|---|---|
| 网页列表 | KaTeX 预渲染 HTML（缓存） | 内联 SVG（CDN） | 渲染失败→显示预生成 PNG |
| 网页详情/编辑 | MathJax v3 | 交互 SVG（可缩放） | 原图 |
| 打印 PDF | 矢量（内嵌数学字体） | 300dpi PNG/SVG 矢量 | — |
| Word | OMML 可编辑公式 | PNG 300dpi | — |
| 移动端 | KaTeX（同构） | SVG 矢量 + 手势缩放 | — |

### 2.6 与 AI 结合（图形的增量生产）
1. **AI 识图生成 DSL**：多模态模型（Qwen-VL 类）读扫描几何图 → 生成 DSL 草稿 → 画板里人工校对。把"重画一张图"的成本从 10 分钟降到 2 分钟。
2. **AI 出题联动**：AI 生成新题时同步生成图形 DSL（函数图像类成功率最高，先开放该类）。
3. **AI 审图**：DSL 渲染结果与原图做相似度比对（SSIM），辅助人工验收。
