# 平台权限体系与运营后台需求（最高权限管理员）

> 版本：v1.1（2026-09-28 深夜，应用户明确要求补充最高权限角色）｜ 关联：02-PRD / 05-接口文档 / 13-任务书

## 1. 角色矩阵（RBAC + 数据权限）

| 角色 | 编码 | 权限范围 | 说明 |
|---|---|---|---|
| **超级管理员** | SUPER_ADMIN | **全部权限**，含系统设置与权限分配 | 最高权限用户，可有多人但操作全部留审计日志 |
| 平台运营 | OP | 广告位、公告、活动、内容运营位、专辑运营 | 日常运营 |
| 学科编辑 | EDITOR | 题目/解析/图形的增删改、审核工作流（终审）、纠错工单 | 按学段×学科分域授权 |
| 客服 | SUPPORT | 用户查询、工单、退款初审 | 不能改题目与广告 |
| 教师 | TEACHER | 组卷/下载/录题投稿/校本空间 | 前台用户 |
| 学生 | STUDENT | 练习/错题/AI 讲题 | 前台用户 |
| 学校管理员 | SCHOOL_ADMIN | 校本空间内批量账号、校本题库 | B 端 |
| 游客 | GUEST | 浏览限流 | 未登录 |

## 2. 超级管理员能力清单（验收基准）

1. **广告位管理（教师端+学生端+小程序全域）**
   - 位置枚举：`home_hero` 首页轮播 / `home_banner` 首页横幅 / `sidebar_teacher` 教师工作台侧栏 / `sidebar_student` 学生端侧栏 / `list_inline` 列表信息流 / `detail_footer` 详情页底部 / `login_promo` 登录页。
   - 每条广告：素材图片（后台可传或填 URL）、跳转链接、投放端（教师/学生/全部）、排序、开始/结束时间、上下线状态、备注。
   - **空位规则：无上线素材时前台渲染虚线占位框（显示"广告位 {位置编码} · 尺寸建议 · 后台可配"），不留空白**。
2. **题目管理**：全字段编辑（题干/选项/答案/解析/知识点/难度/来源）、上下架、批量导入（Excel/Word）、审核工作流终审、AI 生成内容签认、删除（软删+审计）。
3. **用户管理**：查询/详情、教师认证审核、封禁/解封、重置密码、赠送会员；查看任意用户组卷/下载记录（合规审计）。
4. **会员与订单**：会员档位配置、订单查询、退款、点数人工调整。
5. **公告与消息**：全站公告、定向消息推送（教师/学生）、消息中心角标。
6. **系统设置**：站名、**Logo（上传/URL，前台全部占位处自动替换）**、备案号、客服电话、默认学段学科、客服与举报电话。
7. **数据看板**：DAU/组卷量/下载量/题库增长/广告曝光点击/AI 成本。
8. **操作审计**：超管与运营的每一次写操作记录（人/时间/IP/前后值），只读不可改。

## 3. 前台占位规范（用户要求：广告/图片/Logo 位置先空出来）
- 所有前台页面预留：顶部 Logo 槽（`data-slot="logo"`）、广告位槽（`data-slot="ad:home_hero"` 等）、图片素材槽（`data-slot="img:xxx"`）。
- 占位样式统一：虚线边框 + 浅色底 + 槽位编码 + 建议尺寸，见 `prototype/assets/placeholders.css`。
- 上线时后台配置素材后自动替换占位，无需改代码。

## 4. 安全约束（实现验收条件）
- 服务端请求 URL（如广告素材校验、外链预览）仅允许 http/https；请求前校验 host，拒绝 localhost、环回、私有（10/172.16-12/192.168）与保留地址（SSRF 防护）。
- 超管登录必须二次验证（MVP 阶段：独立强口令 + 登录 IP 白名单可配）。
