## 1. 教师端功能地图（对标组卷网信息架构，docs/09 §1）

```
教师用户旅程：注册登录 → 首页选学科 → 选题（章节/知识点/试卷）→ 试题篮 → 智能组卷/汇编
            → 组卷工作台（编辑/换题/导出计费）→ 我的（试卷/录题/积分）→ 会员增值
教师教学旅程：上好课（备课成套资源）→ 布置练习 → 学情/错题本 → 再练卷 → AI 助手（出题/讲题）
```
