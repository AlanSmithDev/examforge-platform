# 教师端前端交付与接口差异

版本：v1.0，2026-09-28。范围仅限 `code/enterprise/frontend`，不表示后端、数据资产或生产部署已完成。

## 1. 当前可运行范围

教师端使用 Vue 3、Vite、Element Plus、KaTeX。路由包括工作台、题库、题目详情、组卷、练习、AI 搜、会员、教学资源、数学图形和个人空间。题库演示数据来自 `src/mock.js`，试题篮、收藏、图形草稿、试卷草稿保存在浏览器 localStorage。演示数据不能作为真实题量、版权、审核状态或学情指标。

本轮完成的可操作流程：题库按关键词、章节、场景、题型、难度和排序筛选并分页；收藏与试题篮可在个人空间查看；试题篮可导入组卷；组卷可生成演示卷、按实际题数/分值统计、重排/换题/删题、保存并恢复本机草稿、浏览器打印；已登录且服务端可用时题目详情可提交纠错工单。图形工作台可绘点、线段、圆、文字并导出不含位图背景的 SVG。

## 2. 企业版接口核对

| 前端动作 | 已有 Java 接口 | 当前差异与接线要求 |
|---|---|---|
| 题库查询 | `GET /api/v1/questions` | 教师端题库目前使用本地演示题。接线前统一 `pageNo/pageSize`、筛选字段与响应 `list/total`；不得把本地分页当作服务端全库分页。 |
| 智能组卷 | `POST /api/v1/papers/generate` | 请求需要 `subjectId`、`structure`、`difficultyTarget`；响应包括 `paperId/count/totalScore/warnings/questions`。当前登录时尝试请求，失败回退演示题。 |
| 导出 | `POST /api/v1/papers/{id}/export` | 返回 `downloadUrl/mode/reason`；需补正式计费确认、格式选择和文件鉴权。演示卷仅调用浏览器打印。 |
| 纠错 | `POST /api/v1/questions/{id}/feedback` | 请求 `targetType/description`。错误类型必须是题干错误、属性错误、解析知识性错误、解析细节错误、其他错误。未登录或失败时不可提示提交成功。 |
| 收藏/题篮 | 题篮服务已有接口 | 当前仅本机保存；需服务端同步、冲突处理、上限、批量操作和跨设备恢复。 |
| 个人资源 | 尚无统一聚合接口 | 需收藏题、资源、试卷草稿、最近使用、个人上传的分页接口。 |
| 数学图形 | 尚无图形资产接口 | 需按第 3 节新增上传、预览、版本与审核接口。 |

接口统一响应以 `{code,message,data}` 为准。401 由登录流处理；无服务端时页面必须显示演示或不可用状态，不得伪报成功。任何真实题目中的 HTML/MathML/SVG 必须经服务端与前端双层白名单处理，当前演示题只来自项目内可信静态数据。

## 3. 数学图形资产与数据库增补

**两类资产分离**：`RASTER_REFERENCE` 为上传的 PNG/JPEG/WebP，用于原图展示和人工重绘参考；`EDITABLE_VECTOR` 为结构化图形 JSON + 服务端生成的净化 SVG，用于二次编辑、缩放和打印。不能把扫描图标为“可编辑”。当前前端只实现本机矢量绘图和图片参考预览，未完成上传、净化、审核。

建议新增 `figure_asset`：`id`、`owner_id`、`kind`、`status`、`source_format`、`object_key`、`preview_key`、`sha256`、`width`、`height`、`byte_size`、`license_id`、`created_at`、`updated_at`。新增 `figure_revision`：`id`、`asset_id`、`version`、`editor_json`、`sanitized_svg_key`、`created_by`、`created_at`；`(asset_id, version)` 唯一。新增 `question_figure`：`question_id`、`asset_id`、`sort`、`alt_text`、`display_width`。大文件存对象存储，表内仅存元数据和对象键；题目发布版本应固定引用图形修订版本，避免后来编辑改变旧卷。

上传链路：浏览器 MIME/大小初筛 → 服务端流式读取并验证 magic bytes → 病毒扫描 → 位图重编码并剥离 EXIF → SVG/XML 禁用脚本、事件属性、外部引用、foreignObject 与嵌入资源 → 对象存储隔离桶 → 审核 → 生成缩略图与打印版 → CDN 分发。建议限制单图 5 MB、尺寸 8000×8000，具体阈值需压测确认。原始 GeoGebra 文件、TikZ 或 JSXGraph 定义可作为私有源文件保存，公开展示只使用经净化的 SVG/位图。无障碍替代文字必填。

建议接口：`POST /api/v1/figures/uploads` 申请上传；`POST /api/v1/figures` 提交元数据/版本；`GET /api/v1/figures/{id}` 获取展示与编辑权限；`POST /api/v1/figures/{id}/revisions` 保存新版本；`POST /api/v1/questions/{id}/figures` 绑定题目；审核接口归内容运营权限。写操作带幂等键与审计记录，图形解析在隔离进程执行。

## 4. 后续验收门槛

资源中心需要真实分类、版权状态、预览/下载和审核工作流；个人空间需要服务端同步；知识点选题与试卷选题目前共享演示题筛选器，仍需独立的数据模型与页面；数学图形还需坐标轴、函数曲线、几何约束、导入 GeoGebra 等专业能力。应按 `docs/09`、`docs/10` 的功能清单逐项验收，而不是用现有演示路由宣称“竞品全功能完成”。

运行：在 `code/enterprise/frontend` 执行 `npm install` 和 `npm run dev`。生产构建执行 `npm run build`。后端网关/数据库未启动时，只验证本地演示流程；联调应启动网关和相关服务并导入合规题目数据。
