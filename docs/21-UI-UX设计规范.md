## 2. 组件规范

- **按钮**：主（蓝底白字）/ 次要（描边）/ 渐变（会员金，仅会员购买与充值）/ 危险（红字描边，仅退款/作废）；统一 `btn btn-*`，小尺寸 `btn-sm`；禁用态 opacity .5 + cursor not-allowed。
- **价格展示**：一律 `¥x.xx`（分→元服务端换算展示）；划线原价仅在营销场景出现；点数展示为整数 + 「点」单位，充值按钮文案带「到账 N 点」。
- **票券（优惠券）**：左 104px 色块（满减=金 / 折扣=蓝 / 点数券=绿）+ 右信息区（名称、限量/限领、有效期、范围）；状态右上角徽章：未使用/锁定中/已使用/已过期/已作废；非 UNUSED 整卡 opacity .55 置灰；撕票虚线为左色块右缘 1px dashed #fff。
- **会员卡（档位）**：`vip-tier` 横排三卡，热卖卡 `hot` 放大 + 金渐变边；价格行「¥25<i>/30 天</i>」；权益列表 ✅/🚫。
- **积分流水行**：变动列 +绿/-红加粗；列序：类型/变动/余额（balance_after）/说明/时间。
- **签到日历**：30 格（30px 圆角方块），已签日=主色白字；上方「已连续签到 N 天 · 今日已签」。
- **Toast**：右上角 2.8s 自动消失，成功 ✅ / 失败 ❌ 前缀，错误文案直接可读（§5）。
- **弹层（收银台）**：遮罩 rgba(15,23,42,.45)，420px 白卡；行序：商品→原价→券下拉→券抵扣→实付（金色加粗+上虚线分隔）→取消/支付双按钮。

## 3. 关键页面布局规格

### 3.1 会员中心 vip.html（已实现，作为基准）
```
[登录门]（无 token 时）：品牌卡 + 预填演示账号 + 一键注册（含邀请码输入）
[权益状态条 me-bar]：会员徽章(金)｜点数余额｜今日免费下载 x/3｜未用券 N｜退出
[三档会员卡] → 立即开通 → 收银台弹层
[点数充值]：4 套餐格（到账点数+赠送标注）→ 充值 → 同一收银台
[优惠券中心]：tab(可领取｜我的优惠券) + 票券网格 + 领取按钮态
[签到+邀请]（左） ｜ [点数明细表]（右）双栏，<768px 单列
```
交互状态：每个数据区必须有 加载中（初始文案）/ 空（「暂无流水」「去可领取看看」）/ 错误（Toast + 保留上一次成功数据）三态。

### 3.2 收银台弹层
- 打开时：`GET /coupons/usable?skuType&originCents` 拉券；可用券进下拉（显示抵扣额），不可用券聚合计数提示「N 张券不可用（门槛/范围不符）」。
- 券切换实时重算实付；支付按钮防重复提交（disabled until 响应）。
- 失败分支话术：42200+needCents →「未达券门槛（需满 ¥50.00）」；其余显示服务端 message。
- 成功：关弹层 → Toast「支付成功：{title}」→ 刷新权益条/流水/券区（三区联动）。

### 3.3 后台商业化运营页 admin（pane-trade）
```
[券模板表单]：2 行 4 列栅格（编码/名称/类型/总量；面额/折扣率/封顶/门槛；限领/天数/范围/备注）→ 创建
[券模板表]：已领/总量 进度可读、状态徽章、作废需 confirm（连带作废提示）
[订单表]：状态筛选下拉；行内操作按状态出现——CREATED→关单，PAID→退款；退款按钮红色
[点数调整]：用户ID+变动+原因一行表单，执行后 Toast 回显新余额
```
EDITOR 角色访问时静默隐藏数据（403 捕获），不暴露接口细节。

## 4. 判价与计费话术（固定文案）

| 场景 | 文案 |
|---|---|
| 免费额度将尽 | 「今日免费下载 x/3 已用完，开通会员不限次」 |
| 余额不足 | 「本次下载需 {needPoints} 点，当前余额 {balance} 点，去充值」 |
| 重复下载 | 「30 天内重复下载不重复计费」 |
| 会员下载 | 「会员专享 · 下载不限次」 |
| 券不可用-门槛 | 「未达券门槛（需满 ¥{threshold}）」 |
| 券不可用-范围 | 「该券仅适用于{scope}」 |

## 5. 错误文案与无障碍

- 错误文案用户可读，不暴露堆栈/SQL/内部码；HTTP 码仅进控制台日志。
- 对比度 ≥4.5:1（正文 vs 白底均满足）；所有按钮/输入有 :focus-visible 描边。
- 金额与点数使用等宽字体（订单号 font-family:monospace）。
- 移动端断点 <768px：卡片网格单列、me-bar 换行、弹层宽度 92vw。
- 图标仅作辅助（emoji 占位，企业版换 SVG 雪碧图），不承载唯一信息。
