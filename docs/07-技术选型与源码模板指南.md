# 技术选型与源码模板指南

> 版本：v1.0 ｜ 原则：主栈与国内教育/电商大厂主流一致（招人容易、资料多），能用成熟开源不重复造轮子，核心差异化（题目渲染、图形 DSL、组卷引擎）自研。

## 3. 外部开源模板评估（可再调研引入）

| 项目 | 结论 |
|---|---|
| 学之思 xzs（考试系统） | 前后端分离、有组卷/考试模块，社区活跃；引入前需核对其 license 与商用条款，主要参考其组卷交互 |
| 芸帆/云帆考试、Exam++ 等 | 多为单机版考试系统，题库规模设计不支持 3000 万用户，仅作功能参考 |
| pptx/docx 生成 | poi-tl（Word 模板）、docx4j（OMML 转换链成熟） |
| 公式/图形 | KaTeX(BSD)/MathJax(Apache)/MathLive(LGPL?)——引入前核对；JSXGraph(LGPL+MIT 可用)；**GeoGebra 商用需授权（已在 06 文档标注风险）** |

> 使用提醒：所有第三方库引入前跑一次 license 清单评审（尤其 GPL 传染性问题），字体使用开源数学字体（Latin Modern/STIX/思源），避免字体版权坑。

## 4. 代码仓库规划（monorepo）

```
examforge/
├── examforge-dependencies/     # BOM 统一版本（借鉴 damai/tianji 模式）
├── examforge-common/           # 通用: 统一响应/异常/工具/幂等/审计注解
├── examforge-api/              # Feign 契约层(服务间 DTO,借鉴 tj-api)
├── examforge-gateway/          # APISIX 或 Spring Cloud Gateway(认证/限流/灰度)
├── examforge-service/
│   ├── user/ auth/ member/ pay/
│   ├── question/ figure/ media/ search/
│   ├── paper/ render/
│   ├── ai-gateway/ ai-tutor/ rag/
│   ├── practice/ school/ admin/ message/
├── examforge-front/
```
