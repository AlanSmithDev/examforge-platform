## 1. 练习与错题域（examforge-practice，端口 8106；MVP 实现在 code/app/server/practice.js）

| 编号 | 需求 | 规则 |
|---|---|---|
| PR-1 | 生成练习 | 按知识点/题型拉题 N 道（Feign 调题库 `/internal/questions/by-kp`），生成 `practice` 记录 |
| PR-2 | 判分 | 客观题自动判分：单选/判断=字符串精确匹配；多选=集合相等（选项有序化）；填空=归一化（去空格/全半角）后相等；解答题=人工批改标记（MVP 记 `PENDING`） |
| PR-3 | 提交 | 批量提交答案 → 逐题判分 → 正确率/错题列表；`practice_answer` 落每题作答与对错 |
| PR-4 | 错题本 | 答错自动入 `wrong_question`（wrong_count 累加，resolved=false）；再练答对 → resolved=true；按知识点聚合查询 |
| PR-5 | 再练卷 | 错题一键再练：取错题知识点 → 回 PR-1 生成新练习（**排除原错题**，避免重复打击信心） |
| PR-6 | 学情 | 按知识点聚合正确率（`GET /report/kp`），支撑前端热力图 |

接口：`POST /practices`（生成）、`GET /practices/{id}`（详情/重做）、`POST /practices/{id}/submit`（作答提交）、`GET /wrong-questions`、`POST /wrong-questions/{qid}/resolve`、`GET /report/kp`。

## 2. AI 域（examforge-ai，端口 8107；MVP 实现在 code/app/server/ai.js）

| 编号 | 需求 | 规则 |
|---|---|---|
| AI-1 | Provider 抽象 | `AiProvider.chat(system,user)`；MOCK（离线返回固定结构，供开发/测试）/ OPENAI_COMPAT（DeepSeek/Qwen/自建 vLLM：`{base}/chat/completions`，Bearer key） |
| AI-2 | 变式出题 | 输入题干 → 提示词模板（保持考点/题型/难度，改情境与数据）→ 返回结构化题目草稿（进审核队列，AI-4） |
| AI-3 | 分步讲题 | 输入题干+答案 → 返回分步讲解文本（SSE 流式为 M2） |
| AI-4 | 治理 | 全部调用落 `ai_log`（provider/model/tokens/耗时）；生成内容一律 `aigc=1` 进审核工作流；配额对接 trade（**已落地**：免费 3 次/日 / 会员 50 次/日，settings 可配，超限 42900 AI_QUOTA_EXCEEDED） |
| AI-5 | 可靠性 | 超时 15s、重试 1 次、失败降级 MOCK 并标记 `degraded=true`；**AI_BASE 经 SSRF 白名单校验**（仅 http/https、禁环回/内网，内网 vLLM 需 AI_ALLOW_PRIVATE=1） |

## 3. 数据库
- 企业版：`06_practice.sql`（practice / practice_answer / wrong_question）、`07_ai.sql`（ai_log）；
- MVP（code/app/server/db.js）：同名表已建——practice(question_ids JSON)、practice_answer(correct 可空=解答题 PENDING)、wrong_question(UNIQUE(user_id,question_id))、ai_log(degraded 标记)。
