# 商业化接口详细字典 —— 会员 / 点数 / 优惠券 / 订单支付 / 下载计费 / 营销

> 版本：v1.0 ｜ 2026-09-28 ｜ 上游：docs/14 §8（接口清单）、docs/16（库表）、docs/05（全局约定）
> 响应包裹：`{ code, message, data }`；认证：`Authorization: Bearer <jwt>`；幂等：下单接口支持请求头 `X-Idempotency-Key`（与 body.idempotencyKey 等价，头优先）。
> 前缀约定：会员 `/api/v1/member`、优惠券 `/api/v1/coupons`、支付 `/api/v1/payments`、交易 `/api/v1/trade`。

## 0. 商业化错误码总表

| code | HTTP | 含义 | 触发场景 |
|---|---|---|---|
| 0 | 200 | 成功 | — |
| 40001 | 409 | 状态机非法跃迁 | 已支付订单再次支付、已核销券再核销 |
| 40100 | 401 | 未登录/凭证过期 | — |
| 40301 | 403 | 无权限 | 非 SUPER_ADMIN 调整点数 |
| 40400 | 404 | 资源不存在 | 订单号/券不存在或非本人 |
| 42200 | 422 | 参数校验失败 | 缺 idempotencyKey、档位不可售、券门槛不足等 |
| 42900 | 429 | 配额/余额不足 | 点数扣减不足（data.needPoints）、券已被领完（data.reason=COUPON_SOLD_OUT） |
| 42901 | 409 | 重复请求 | 回调 DUPLICATED（返回首次结果，message 提示） |
| 50010 | 500 | 系统错误 | 履约事务回滚等 |

## 1. 会员 /api/v1/member

### 1.1 GET /member/plans（公开）
档位列表（含点数套餐，收银台一次拉取）。
```json
data: { "plans": [ { "id":2, "code":"TEACHER_PRO", "name":"教师优享", "priceCents":2500, "durationDays":30,
         "subjectId":null, "benefits":["下载不限次","AI 50次/日"], "purchasable":true } ],
        "pointPackages": [ { "id":1, "points":5000, "bonusPoints":500, "priceCents":5000, "label":"50元档" } ] }
```

### 1.2 GET /member/me（登录）
唯一权益入口（M-3 entitlement）。
```json
data: { "member": { "active": true, "planCode": "TEACHER_PRO", "expireAt": "2027-12-31", "remainDays": 458 },
        "points": { "balance": 320, "freeDownloadsPerDay": 3, "freeUsedToday": 1 },
        "coupons": { "unused": 2 } }
```

### 1.3 POST /member/orders（登录，幂等）
下单。body：`{ "skuType":"MEMBER|POINTS|PAPER", "planCode":"TEACHER_PRO" | "packageId":1 | "paperId":9, "couponId":null, "channel":"MOCK", "idempotencyKey":"uuid" }`（PAPER 单走 §4 判价后创建）。
校验顺序：幂等键查原单 → SKU 存在与可售 → 券可用性（门槛/范围/状态）→ 价格计算 → 建 CREATED 单 + 券 FROZEN（同事务）。
```json
// 200
data: { "orderNo":"ZJ260928031122834721", "status":"CREATED", "originCents":2500, "discountCents":0,
        "payCents":2500, "couponId":null, "expireAt":"2026-09-28 03:41", "payUrl":"/prototype/vip.html?pay=ZJ..." }
// 错误：42200 {message:"优惠券门槛不足", data:{needCents:1000}} ｜ 40001/40400/42200 常规
```
**响应头**：`X-Idempotent-Replay: true` 标记命中原单。

### 1.4 GET /member/orders?pageNo&pageSize（登录）｜ GET /member/orders/{orderNo}（登录）
我的订单分页 / 订单详情（`data.order` + `data.coupon` 快照 + `data.fulfil`）。

## 2. 支付 /api/v1/payments

### 2.1 POST /payments/mock-notify（沙箱）
body：`{ "orderNo":"ZJ...", "callbackId":"cb-uuid", "amountCents":2500 }`。**仅 NODE_ENV!=production 可用**，生产为渠道验签回调（WECHAT/ALIPAY，O-4/O-6）。
处理：`payment_log` 先落流水（uk_callback 防重）→ 已 PAID 直接返回首次结果（幂等三板斧）→ 金额与订单一致校验 → 履约事务（O-5）：订单 PAID → 券核销 → 开会员/加点数 → 流水成对。
```json
// 首次：data:{ "orderNo":"ZJ...", "status":"PAID", "fulfil":{...} }
// 重复回调：HTTP 200 code=42901 message="重复回调已忽略" data=首次履约结果
```

### 2.2 POST /payments/refund/{orderNo}（SUPER_ADMIN）
见 docs/16 §8 顺序；`data:{orderNo,status:"REFUNDED",returned:{couponId,points,days}}`。

## 3. 优惠券 /api/v1/coupons

### 3.1 GET /coupons/available（登录）
可领列表（status=1、领取窗口内、未领满、个人未超限；附 `claimState: CLAIMABLE|SOLD_OUT|LIMIT_REACHED|NOT_STARTED|ENDED`）。
```json
data: { "list": [ { "id":1, "code":"NEW10", "name":"新人立减券", "type":"FULL_REDUCTION",
          "amountCents":1000, "thresholdCents":0, "total":100, "claimed":37, "perLimit":1,
          "validDays":7, "scope":"ALL", "claimState":"CLAIMABLE" } ] }
```

### 3.2 POST /coupons/claim（登录）body:`{ "templateId":1 }`
条件 UPDATE 原子领取（16 号 C-3'）。成功 `data:{couponId, expireAt}`；领完 `42900 + data.reason="COUPON_SOLD_OUT"`；超限 `42900 + reason="PER_LIMIT"`；窗口外 `42200`。

### 3.3 GET /coupons/mine?status=UNUSED|FROZEN|USED|EXPIRED|ALL（登录）
```json
data: { "list": [ { "id":11, "templateCode":"NEW10", "name":"新人立减券", "type":"FULL_REDUCTION",
        "amountCents":1000, "discountRate":0, "maxDiscountCents":0, "thresholdCents":0, "scope":"ALL",
        "status":"UNUSED", "expireAt":"2026-10-05", "usedOrderNo":null } ] }
```

### 3.4 GET /coupons/usable?skuType=POINTS&originCents=10000（登录）
收银台下拉：对当前订单可用的 UNUSED 券 + 不可用券及原因（`blockedReason: THRESHOLD/SCOPE/EXPIRED`）。

### 3.5 券模板管理（SUPER_ADMIN/OP）
`POST /admin/coupons`（创建，字段见 16 §4）→ `data:{id}`；`GET /admin/coupons?pageNo`；`PUT /admin/coupons/{id}/status` body:`{"status":0|1|2}`（**status=2 作废连带全部用户券 CLOSED**，审计）。

## 4. 下载计费 /api/v1/trade

### 4.1 GET /trade/billing?paperId=9（登录；或 questionCount&paperHash）
判价（D-1 顺序：30 天重复下载 → 会员 → 免费 3 次/日 → 点数）。
```json
data: { "mode":"POINTS", "needPoints":400, "reason":"TIRED_21_50",
        "billing": { "freeDownloadsPerDay":3, "freeUsedToday":1, "memberActive":false, "repeat":false } }
// mode=MEMBER / FREE_QUOTA / FREE_REPEAT(reason="REPEAT_30D") 时 needPoints=0
```

### 4.2 POST /trade/consume（登录）body:`{ "paperId":9, "paperHash":"sha256", "questionCount":19 }`
**导出成功后调用**。服务端复算判价：FREE_* → 仅落 download_record；POINTS → 条件 UPDATE 扣减（不足 42900 `data:{needPoints}`）+ 落记录 + `CONSUME` 流水。`data:{charged, mode, balance}`。

### 4.3 GET /trade/points?pageNo&pageSize（登录）
`data:{balance, log:[{id,bizType,delta,balanceAfter,note,orderNo,createdAt}]}`

### 4.4 POST /trade/points/adjust（SUPER_ADMIN，审计）body:`{ "userId":5, "delta":-100, "note":"误充回收" }`
条件 UPDATE 防透支（回收不足钳位 0 并注明）；`ADMIN_ADJUST` 流水。

## 5. 营销 /api/v1/trade

### 5.1 POST /trade/signin（登录）
当日已签 → `42900 data.reason="ALREADY_SIGNED"`。成功：
```json
data: { "signedDate":"2026-09-28", "continuous":7, "pointsGained":7,
        "memberMultiplier":2, "basePoints":1, "streakBonus":5,
        "calendar": ["2026-09-22","2026-09-23","..."], "balance": 87 }
```
规则：`points = (基础1 + 连续档3天+2/7天+5/15天+10/30天+20) × (会员?2:1)`；昨日未签连续清零；`sign_in_log uk(user_id,sign_date)` 兜底。

### 5.2 GET /trade/signin（登录）— 当月日历 + 连续天数 + 今日是否已签

### 5.3 GET /trade/invite（登录）
`data:{ inviteCode:"ZJ8K3M", invited:3, pointsEarned:60, records:[{mobileMasked:"139****0002",points:20,createdAt}] }`

### 5.4 注册绑定（挂 /auth/register）
body 增可选 `inviteCode`：注册事务内绑定 `inviter_id` → 双方各 +20 点（`GIFT_INVITE` 流水）+ 新人礼包（K-1：NEWBIE_7D 会员 7 天 + 10 点 + 新人券）；`invite_record uk(invitee_id)` 保证一人仅一次；无效码不阻断注册。

## 6. 导出与计费联动 /api/v1/papers

### 6.1 GET /papers（登录）—— 我的试卷列表
`data:{list:[{id,title,total_score,created_at}]}`（导出/判价接线数据源）。

### 6.2 POST /papers/{id}/export（登录，企业版 examforge-paper）body 可选：`{"paper":"A4|A3","columns":1|2,"answerMode":"INLINE|SEPARATED|NONE"}`（C6 版面参数，全部可缺省=历史默认 A4 单栏题后随卷）
导出入口（打印就绪 HTML；配置 `RENDER_URL` 时同管线直出 PDF）。流程：`billing()` 判价（30 天重复→已购→限时免费→会员→免费额度→点数，支持 paperId 的限时免费判定）→ POINTS 且余额不足 → `42900 data.reason` 前台引导充值 → 生成产物 → `consume()` 扣费落记录 → 返回下载地址：
```json
data: { "downloadUrl": "/api/v1/papers/export/download/paper-9-a1b2c3d4-a3c2s.pdf",
        "mode": "POINTS", "reason": "…", "charged": { … } }
```
版面规则（docs/23 C6 口径）：A3 双栏自动横向（对折成 A4 试卷惯例）；answerMode=SEPARATED 题区剥离答案、末尾独立答案页（page-break）；NONE 学生卷无答案。**产物文件名带版面标签**（`-{paper小写}c{columns}{i|s|n}`，如 `-a3c2s`）防不同版面同名互覆；下载端点 `GET /papers/export/download/{file}` 白名单正则兼容带/不带标签。
计费口径：**内容指纹 paperHash 不含版面**（docs/14 D-1 的 30 天重复下载窗按题目集合判定，换版面不重置窗口）。

### 6.3 PUT /papers/{id}（登录，教师端工作台保存）
整卷覆盖式保存（顺序=数组顺序）。body：`{"title":"卷名","questions":[{"questionId":3,"score":5},…]}`。
```json
data: { "paperId": 9, "title": "编辑后的卷子", "totalScore": 88, "count": 19,
        "questions": [ { "id": 3, "type": "单选题", "difficulty": 3, "score": 5 } ] }
```
校验（事务内）：归属校验（40400）、题目 ≥1（42200）、ID 无重复（42200）、全部上架（42200）。**保存后 paper_hash 变化 → 30 天重复下载判定自动失效**（新结构重新判价）。

### 6.4 POST /papers/{id}/replace（登录，智能换题）
body：`{"questionId":3}`。规则：同学科同题型、难度就近（同档 → ±1）、排除卷内已有、取使用次数最少（冷门优先推荐语义）；分值保留原题。
```json
data: { "removed": 3, "added": { "id": 27, "type": "单选题", "difficulty": 3, "coefficient": 0.66,
        "score": 5, "kp_names": "双曲线,离心率", "stem": "…", "options": […], "answer": "A", "analysis": {…} } }
```
错误：40400 题目不在卷内 / 无可用替换题。

### 6.5 GET /questions/kps（公开）—— 知识点聚合（知识点选题视角）
`data:{list:[{name,count}]}`（上架题按 kp_names 拆分聚合，题量降序 Top50）。

### 6.6 GET /papers/public（登录）—— 公开示范卷（教师端试卷选题，docs/25 TJ-10~11）
查询：`category=同步教学|阶段测试|高考备考|竞赛`、`level=普通|精品|特供`、`year`、`pageNo/pageSize`。
```json
data: { "total": 3, "rows": [ { "id": 41, "title": "2026 届高三高考模拟卷（一）", "level": "精品", "year": 2026,
  "region": "江苏", "category": "高考备考", "downloads": 2141, "total_score": 132, "question_count": 18 } ] }
```

### 6.7 GET /papers/public/{id}/preview（登录）—— 整卷试读 30%（TJ-12）
`data:{ paper:{id,title,level,year,region,category,totalScore,totalCount,readCount}, questions:[{id,type,difficulty,kp_names,stem,options}] }`
规则：`readCount = max(1, ceil(totalCount×0.3))`，**不含 answer/analysis**（付费墙语义）；试读题 id 可进试题篮（抽题重组 TJ-13）。

### 6.8 导出归属放宽（TJ-14）
`GET /papers/{id}/export`：本人试卷 **或 is_public=1** 均可导出（公开卷计费照常走 D-1 判价，导出后 downloads+1）；非公开非本人仍 40400。

### 6.9 教师工具箱（TJ-80/84/85/86/88，docs/25 第二批）

**导出参数（TJ-86/TJ-100）**：`GET /papers/{id}/export?format=html|docx&answerPos=end|separate|none&paperSize=A4|A3&columns=1|2&fontSize=s|m|l`
- `format=docx`：Word 原生公式（LaTeX→MathML→OMML，temml+mathml2omml），公式在 Word 中可二次编辑；响应头 `X-Math-Count` 报告公式转换数；单条公式失败退回该条 LaTeX 原文不中断整卷
- `end`=每题行内附答案+简析；`separate`=行内隐藏+末尾独立"参考答案页"（page-break-before）；`none`=纯题
- A3/双栏/字号均落到打印 CSS（@page size / column-count / font-size）

**组卷模板（TJ-80）**：
- `POST /papers/templates` body:`{name, subjectId, structure:[{type,count,score}], difficultyTarget}` → `data:{id}`
- `GET /papers/templates` → `data:{list:[{id,name,subjectId,structure,difficultyTarget,createdAt}]}`（本人）
- `DELETE /papers/templates/{id}`（本人，40400 他人的）

**收藏（TJ-85，toggle）**：
- `POST /papers/favorites` body:`{questionId}` → `data:{questionId, favorited:true|false}`（再次调用=取消）
- `GET /papers/favorites?pageNo` → `data:{total, rows:[题目卡字段]}`（**不含 answer**）

**精品专辑（TJ-88，公开）**：
- `GET /papers/albums` → `data:{list:[{id,title,brand,description,coverEmoji,paperCount}]}`
- `GET /papers/albums/{id}` → `data:{…album, papers:[{id,title,level,year,region,category,downloads,totalScore,questionCount}]}`

**生成增强**：`POST /papers/generate` 支持 `kp`（知识点限定）与响应新增 `structure/subjectId/title`（平行卷蓝图复原）；generate 响应每题含 `kp`（细目表与覆盖检查数据源）。

## 7B. 练习与错题域（docs/15 §1，examforge-practice / MVP 已落地）

### 7B.1 POST /practices（登录）body:`{"mode":"KP|REPEAT","subjectId":3,"kp":"函数模型","type":"单选题","count":10}`
- KP：按条件抽题；REPEAT：取未解决错题的知识点抽新题（**排除原错题**，PR-5）。
```json
data: { "practiceId": 7, "mode": "KP", "total": 10,
  "questions": [ { "id": 3, "type": "单选题", "difficulty": 3, "coefficient": 0.65, "kp_names": "…", "stem": "…", "options": [{"l":"A","v":"…"}] } ] }
```
题目**不含答案与解析**（防刷）。错误：42200 条件无题/错题本为空。

### 7B.2 GET /practices/{id}（登录）—— 练习详情（重做）
### 7B.3 POST /practices/{id}/submit（登录）body:`{"answers":[{"questionId":3,"answer":"B","durationMs":45000}]}`
判分规则（PR-2）：单选/判断=精确匹配；多选=集合相等（乱序容忍）；填空=归一化（去空格/全半角/中英文逗号）后相等；**解答题 correct=null（PENDING 人工批改）**。
```json
data: { "practiceId": 7, "total": 10, "objective": 9, "correctRate": 0.78,
  "wrongIds": [11, 19],
  "results": [ { "questionId": 11, "correct": 0, "yourAnswer": "C", "answer": "B",
                 "analysis": {"brief":"…","solve":"…","comment":"…"}, "kpNames": "…" } ] }
```
副作用（PR-4）：答错 → 错题本 wrong_count+1、resolved=0；再练答对 → resolved=1。

### 7B.4 GET /wrong-questions?subjectId=（登录）
`data:{list:[{id,wrong_count,resolved,last_wrong_at,type,difficulty,kp_names,stem}]}`（仅未解决）。

### 7B.5 POST /wrong-questions/{questionId}/resolve（登录）
手动标记已掌握；不存在/已解决 → 40400。

### 7B.6 GET /report/kp（登录）—— 学情聚合（热力图数据源）
`data:{list:[{kp,answered,correct,wrong,correctRate}]}`（按 wrong 降序）。

### 7B.7 企业版：作业-错题本联动（examforge-practice，docs/26 F-XKW-12 考后诊断闭环）
作业域三个判分落点（学生提交 /students submit、教师批改 /{id}/students/{sid}/grade、扫描导入 /{id}/scans/{scanId}/import）统一经 **WrongBookRules 差分**联动 `wrong_question` 表（与练习线 PR-4 同表同口径）：
- 新进入错误态（待批→错 / 对→错改判）→ 入错题本（`wrong_count+1`、置未解决，**带 kpNames** 供错题本展示与再练）；
- 维持错误态（错→错，扫描重导/重复批改）→ **不动作**（防 wrong_count 虚高）；
- 判对 → 解决既有未解决错题（幂等；跨作业/练习口径一致）；
- 待批改（correct=NULL）→ 不触碰错题本。
入本的错题可被练习线消费（REPEAT 排除原错题 / WRONG 错题再练卷）。

### 7B.8 企业版：学生个体学情报告（examforge-practice，e卷通"个性化报告/考后诊断"）
- `GET /api/v1/assignments/my/report`（登录，学生自查）
- `GET /api/v1/assignments/students/{studentId}/report`（教师查学生；**鉴权**：须为该生所在任一作业的布置者，否则 `40301`；学生查本人亦走此端点）
```json
data: { "studentId": 1001, "assignments": 3,
        "overall": { "answered": 30, "correct": 24, "wrong": 4, "pending": 2, "correctRatePct": 80.0 },
        "trend": [ { "assignmentId": 9, "title": "…", "myStatus": 2, "score": 85.0, "answered": 10, "correctRatePct": 80.0 } ],
        "weakKnowledgePoints": [ { "kp": "…", "total": 8, "wrong": 3, "correctRatePct": 62.5 } ],
        "wrongBook": [ { "questionId": 12, "kpNames": "…", "wrongCount": 2, "lastWrongAt": "…" } ] }
```
口径：trend 取最近 10 次作业（名单倒序）；weakKnowledgePoints 为**行级**聚合（每条作答计一次，与班级报告的按题聚合区分）；wrongBook 为未解决错题 TOP10（按错误次数、最近出错倒序）；班级报告 `GET /assignments/{id}/report` 同步补 `rosterRows`（studentId/status/score）供教师下钻。

## 7C. AI 域（docs/15 §2，MOCK/OPENAI_COMPAT 双通道）

> 7C.1~7C.3 为 **MVP 侧**端点（code/app）；**7C.4 起为企业版** examforge-ai 端点（网关 `/api/v1/ai/**`，配额与日志口径见各条）。

### 7C.1 GET /ai/quota（登录）

data: { "quota": 50, "used": 12, "left": 38, "member": true,

配额：免费 3 次/日（settings `ai_quota_free`）、会员 50 次/日（`ai_quota_member`），按 ai_log 当日行数计。

### 7C.2 POST /ai/variants（登录）body:`{"questionId":3}` 或 `{"stem":"题干"}`
变式出题（AI-2）。返回**草稿**，不直接入库：
```json
data: { "draft": { "kind": "VARIANT", "marker": "[AI-草稿]", "stem": "[AI-草稿] 变式题干：…",
         "questionId": 3, "type": "单选题", "difficulty": 3, "kpNames": "…", "aigc": 1, "reviewStatus": "PENDING_REVIEW" },
       "quota": { "quota": 3, "used": 1, "left": 2, "member": false } }
```
超配额 → `42900 data.reason="AI_QUOTA_EXCEEDED"`。

### 7C.3 POST /ai/explain（登录）body:`{"questionId":3}` 或 `{"stem":"…","answer":"B"}`
分步讲题（AI-3）：`data:{kind:"EXPLAIN", steps:"第 1 步·审题：…\n第 2 步·思路：…", provider:"MOCK", degraded:false, quota:{…}}`。

**Provider 配置（环境变量）**：`AI_PROVIDER=MOCK|OPENAI_COMPAT`、`AI_BASE=https://…/v1`（SSRF 白名单校验：仅 http/https、禁环回/内网，自建内网 vLLM 需显式 `AI_ALLOW_PRIVATE=1`）、`AI_KEY`、`AI_MODEL`；15s 超时失败自动降级 MOCK（degraded=1，AI-5）。

### 7C.4 企业版：POST /ai/search（登录，examforge-ai，docs/23 §3 S-1~S-3）
body：`{"query":"高二 立体几何 解答题 较难"}`。MOCK 通道规则解析（难度词/题型词/知识点词）/ 真实通道 LLM 意图解析（失败降级规则解析）→ `/internal/questions/search` 统一检索（ES 优先降级 LIKE，limit 10）：
```json
data: { "parsed": { "keyword": "立体几何", "type": "解答题", "difficulty": 4 },
        "count": 3,
        "list": [ { "id": 12, "type": "解答题", "difficulty": 4, "coefficient": 0.6, "kpNames": "…", "stem": "…" } ] }
```
**不计 AI 配额、不落 ai_log**（文本检索成本低，与拍照搜题口径不同）。缺 query → `42200`。

### 7C.5 企业版：GET /ai/explain/stream?stem=…&answer=…（登录，SSE）
`text/event-stream`：逐步推送讲题步骤——事件 `step`（data 为 `{step,text,latex}`）至事件 `done`（data="true"）；服务端 30s 超时。当前为步骤级模拟流（真实 token 级流式为 M2）。

### 7C.6 企业版：POST /ai/photo-search（登录，C7 拍照搜题，docs/23 §3A——契约以该节为准）
body：`{"imageBase64":"data:image/png;base64,…|纯base64","mime":"image/png（可缺省，从 data URL 头解析）","hint":"识别失败时的文字补充（可选）"}`。
链路：图片校验（jpg/jpeg/png/webp、解码后 ≤8MB）→ chatVision 提取题干 → `PhotoSearchRules.extractKeywords` 关键词（停止词切分/纯中文段/长度夹取 [2,12]/去重 ≤6）→ `/internal/questions/search` 逐词检索（前 3 词内首个非空即止）→ `matchScore`（命中关键词数/总数）降序重排：
```json
data: { "recognized": true, "provider": "MOCK", "degraded": false, "costMs": 12,
        "stem": "已识别题干…", "keywords": ["函数", "两个零点", "实数", "取值范围"], "count": 3,
        "list": [ { "id": 12, "…": "…", "matchScore": 0.75 } ] }
```
降级矩阵：Provider 无视觉/识别失败/JSON 解析失败 → 有 `hint` 走文本规则解析检索（`hintUsed:true`）；无 hint 返回 `reason` 引导文案；视觉调用异常降级 MOCK 重试（`degraded:true`）。MOCK Provider 对含"题干"标记的提示词返回确定性伪题干（扫描转录场景不受影响，仍未识别驱动人工转录）。
**计 AI 配额**（免费 20 次/日、会员 200 次/日，`examforge.ai.quota-*-per-day`，超限 `42900`）+ 落 ai_log（scene=`PHOTO_SEARCH`）。校验失败 `42200`（中文文案直出）。

## 9. 验收映射（与 14 §9、18 号测试用例一一对应）
1. 幂等：同 key 两次 1.3 → 同 orderNo + `X-Idempotent-Replay: true`。
2. 状态机：2.1 两次 → 第二次 42901；CLOSED 后 2.1 → 40001。
3. 券：3.2 领完 42900/COUPON_SOLD_OUT；同券两单仅一单成功；门槛不足 42200；退款券返还。
4. 点数：4.2 余额不足 42900；充值到账=套餐 points（含 bonus 分两笔流水）。
5. 计费：4.1 十题卷 needPoints=100；会员 mode=MEMBER；30 天重复 FREE_REPEAT。
6. 履约：会员到期叠加正确、流水 balance_after 连续成对。
