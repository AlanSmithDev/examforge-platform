# 开发路线图与里程碑

> 版本：v1.0 ｜ 团队假设：后端 6、前端 4、算法 2、测试 2、UI 1、产品 1、运维 1（共 17 人，可分阶段到位）

## 1. 里程碑总览

| 阶段 | 周期 | 目标 | 关键交付 |
|---|---|---|---|
| **M0 立项与设计定稿** | 4 周 | 文档评审通过、UI 规范、环境搭建 | 本文档集定稿、技术 POC（DSL 渲染/公式导出 Word/分片压测）、UI 设计系统 |
| **M1 MVP 高中数学打样** | 12 周 | 数学单学科跑通"找题→组卷→导出" | 题库中心（筛选/详情/试题篮）、手动+智能组卷、公式预渲染、图形渲染器+画板 MVP（点线圆+函数绘图）、PDF/Word 导出、免费+点数支付、运营后台最小闭环、题目审核工作流 |
| **M2 AI 与全学科** | 12 周 | 全学科扩科 + AI 差异化上线 | 知识点体系扩科、模板库 300+、细目表/平行卷、AI 组卷/AI 出题/AI 解析审校、OCR 录题流水线、教师认证体系 |
| **M3 学生端与学校版** | 12 周 | 双端闭环 + B 竀收入 | 学生 uni-app（练习/错题/AI 讲题）、作业布置与统计、校本题库/备课组、学校批量账号、优惠券体系 |
| **M4 规模化** | 8 周 | 扛住开学季峰值 | 全链路压测（影子库）、多级缓存全覆盖、限流降级演练、两地三中心容灾、等保三级测评、GA 发布 |

## 2. M1 内部迭代拆解（双周迭代）
- I1：工程骨架（按 07 文档 monorepo，复用天机学堂/大麦框架）、DDL 落库、登录 JWT、学科/知识点配置
- I2：题目模型+录入后台+审核流、ES 索引与搜索
- I3：题目详情页（KaTeX 预渲染管线）、试题篮
- I4：图形 DSL v1+渲染器+服务端 SVG/PNG、函数绘图器
- I5：手动组卷+试卷工作台（换题/排序/分值）
- I6：智能组卷引擎（约束求解：知识点覆盖/难度分布/去重）+ 报告
- I7：导出管线（PDF 排版/答题卡/Word+OMML）+ 下载任务中心
- I8：会员/点数/支付、官网首页、性能达标（P95<300ms）+ 压测 → MVP 发布（种子学校 20 所）

## 3. 风险登记表

| 风险 | 等级 | 对策 |
|---|---|---|
| 题库版权争议 | 高 | 题源合规档案、原创+AI 生成+出版社合作、审计日志 |
| 图形数字化工作量大 | 高 | 模板库优先、AI 识图转 DSL、图片题单独池渐进数字化 |
| LLM 成本失控 | 中 | 私有化为主、token 配额、成本看板周报 |
| 组卷引擎质量（出偏卷） | 中 | 蓝图校验+组卷报告+教师评分回流迭代 |
| 头部竞品渠道挤压 | 中 | 先做教师个人口碑（免费诚意+导出体验），再进学校采购 |
| 招聘到位延迟 | 中 | M1 骨架复用成熟脚手架降低对高级人力依赖 |

## 4. 验收门槛（GA 标准）
- 功能：PRD P0 全部验收；数学图形三端一致性抽检合格率 ≥98%。
- 性能：3.1 节容量模型 1.5 倍压测通过；导出任务成功率 ≥99.9%。
- 安全：渗透测试通过、SSRF/越权/防盗链专项用例全绿。
- 数据：题库 ≥50 万题（数学全量+物理化学启动）、结构化率 ≥95%。
