# 多学段扩展方案 —— 覆盖小学、初中、高中、大学、考研（2026-09-28 用户决策）

> 原则：**一套平台、多学段域隔离**。学段(stage)是继学科之后的第一维度：知识点树、教材版本、题型体系、场景、会员定价全部按学段域配置，题库按"学段×学科"分域存储与运营。
> 打法：高中数学打样 → 高中全科 → 初中 → 小学 → 考研（考研客单价最高、内容最稀缺，作为第二增长曲线）。

## 1. 学段×学科矩阵（M1→M4 覆盖计划）

| 学段 | 学科 | 教材/考试版本 | 特色题型/标签 | 阶段 |
|---|---|---|---|---|
| 小学 | 数学/语文/英语 | 人教/北师大/苏教/沪教版…多版本 | 口算、竖式、应用题、看图列式、拼音标注；难度仅三档 | M3 |
| 初中 | 数/语/英/物/化/生/政/史/地 | 人教/北师大/苏科/浙教(2024 新课标) | 中考真题体系、自招题、实验探究题 | M2 |
| 高中 | 数/语/英/物/化/生/政/史/地 + 信息技术/通用技术/日语 | 人教A/B、各省市新高考 | 新高考 19 题结构、压轴题、强基/竞赛 | **M1 打样(数学)** |
| 大学 | 高数/线代/概率论/大英四六级/专业课公共课 | 同济高数等经典教材 + 四六级真题 | 期末真题、四六级真题、课后习题讲解 | M3 |
| 考研 | 政治/英语一/英语二/数学一/二/三/396经济类/408计算机/西医综合/法硕/管综 | 统考大纲 + 自命题院校真题库 | 大纲考点体系、年份卷种(2020~2027)、专项(如数学的选择填空+大题) | M2-M3 |

## 2. 数据模型增量（04 文档补丁）

```sql
-- 新增学段维表；subject 挂 stage
CREATE TABLE `stage` (
  `id` TINYINT PRIMARY KEY COMMENT '1小学 2初中 3高中 4中职 5大学 6考研',
  `name` VARCHAR(20), `sort` INT
) COMMENT '学段';

ALTER TABLE `subject`
  ADD COLUMN `stage_id` TINYINT NOT NULL AFTER `id`,
  ADD KEY `idx_stage` (`stage_id`);
-- subject 从"语文/数学"变为 (stage_id, name) 唯一：高中数学 与 考研数学 是两个 subject

-- 知识点树/章节树/题型/场景/难度档 均挂 stage 域（配置按学段加载）
ALTER TABLE `knowledge_point` ADD COLUMN `stage_id` TINYINT NOT NULL, ADD KEY `idx_stage` (`stage_id`);
ALTER TABLE `textbook_version` ADD COLUMN `stage_id` TINYINT NOT NULL;
CREATE TABLE `question_type` (
  `id` INT PRIMARY KEY, `stage_id` TINYINT, `subject_id` TINYINT,
  `name` VARCHAR(30) COMMENT '单选题/概念填空/应用题/作文/翻译/408综合应用…',
  `detail_types` JSON COMMENT '细分题型数组', `default_score` TINYINT, `sort` INT
) COMMENT '题型体系按学段学科配置(替代原枚举)';

-- question 主表冗余 stage_id 做分片路由首键（subject_id 已含学段语义，路由不变：
-- 分片键=subject_id（已按学段学科分域），ES 索引按 stage 建独立索引：es_question_{stage}
-- 难度档按学段差异化：小学 3 档 / 初高中 3 档+系数 / 考研 3 档+系数，difficulty 字段语义由配置定义
```
- **考研真题卷种模型**：`region_code` 复用为"卷种"（数一/数二/数三/396/408/英一/英二/政治统考…），`year` 2020~2027；自命题院校建 `school_source` 表（考研专业课按院校归档）。
- **搜索**：ES 按学段分索引，AI 搜默认带学段上下文（顶部学段学科定位器注入）。

## 3. 架构影响（03 文档补丁）
- 配置中心(Nacos)新增"学段域配置包"：题型/场景/难度/版本树按 stage 加载，热更新。
- 审核编辑团队按学段×学科分组（小学编辑需要不同的质量标准：题面趣味性/无超纲）。
- AI 出题按学段切换提示词包与验算器（小学整数域验算 / 考研 SymPy 微积分线代验算）。
- 容量影响：题库总目标上调至 **5000 万题**（全学段），分片库数预留 32 库。

## 4. 产品影响
- 全站顶部"学段学科定位器"（对标菁优"南京市 | 初中数学 · 全年级"，我们升级为"江苏 | 高中数学 · 高三"四维），记忆用户选择，跨端同步。
- 首页/导航/筛选全部按学段域动态渲染；会员定价按学段差异化（考研会员客单价最高：29→49 元/月档）。
- 考研专区（对标高考专区）：大纲考点树、真题按卷种年份、院校自命题库、政治/英语刷题卡。
- 上好课（小初）→ 同步教辅形态；大学/考研无"上好课"，替换为"备考规划"板块。
