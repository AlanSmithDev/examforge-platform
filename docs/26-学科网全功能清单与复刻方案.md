3. **预览限制**：文档类免费预览 33%；组卷网题目看题干、解析付费。
4. **计数公开化**：用户总数、日/周更新量、题目被组卷次数、卷引用数、资源浏览/下载量全部前台展示（信任构建），我们全量保留。
5. **URL/ID 体系**（参考其命名哲学，自建映射）：学科网 `11p{id}.html`（11=高中数学学科码）/`11q{id}.html`（题）/`/zsd{id}/`（考点）/`/tre5-{id}/`（素养）/`/soft/{id}.html`（资源）——我们采用 `{subjectCode}q{snowflake}` 可读 URL + 全局雪花 ID，学科码表入 `subject` 表。
6. **更新节奏**：分钟级试卷上架流（首页滚动）——依赖入库流水线自动化程度，是我们 docs/27 的产品化 KPI。

## 11. 合规红线与对策（学科网启示）

1. 学科网页脚明确"**题库自主建设**"+ 全站版权声明 + 版权异议通道：题库型平台的合规姿势 = 自建 + UGC 签约 + 侵权响应。我们的对策：
   - 内容四来源：**公开数据集（题库/ 目录现状，来源可溯 source_url）+ 自建录入 + UGC 签约上传 + AI 生成（aigc=1 标识）**；不抓取任何商业题库站（题库/README §3 已有 robots 实测结论）。
   - 上线 F-XKW-14 版权服务中心（异议申诉+下架 SLA+签约合同管理），与 docs/20 安全合规规范合并执行。
   - 文档类资源（课件教案）版权风险高于题目，P1 资源站以**自有出版合作 + 签约作者**供给，不做搬运。
2. 滑块验证/风控：学科子站有人机验证与登录墙——我们的公开页面全部可匿名浏览（SEO 友好），写操作与下载才要求登录，风险点集中在下载接口防盗链（签名 URL + 限次）。
3. 数据披露口径：前台公开计数（用户/更新量）需与后台对账任务一致，避免广告法风险。
