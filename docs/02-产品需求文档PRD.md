## 1. 产品概述

### 1.1 一句话定位
面向**小学、初中、高中、大学、考研全学段**师生与学校的"结构化题库 + AI 智能组卷"云平台（2026-09-28 用户决策扩展学段，见《11-多学段扩展方案》）：题目全结构化（LaTeX 公式 + 白底统一图形），组卷专业高效，AI 原生，下载即所得。
> 落地节奏：高中数学打样（M1）→ 高中全科 + 初中（M2）→ 小学 + 大学/四六级（M3）→ 考研专区（M2-M3，客单价最高作为第二增长曲线）。

### 1.2 目标用户与画像
| 角色 | 画像 | 核心诉求 | 付费意愿 |
|---|---|---|---|
| 高中教师（核心） | 全国约 120 万高中教师，带 2-4 个班，周均出卷 2-3 份 | 10 分钟出一份优质卷、公式图形不糊、能导出 Word 改 | ★★★★★（个人会员/学校报销） |
| 教研组长/备课组 | 名校教研组，统一命题 | 校本题库、细目表、审题协作、平行卷 | ★★★★★（学校采购） |
| 高中生/家长 | 3000 万在校高中生，特别是高三 | 刷题、错题、讲题、学情 | ★★★（订阅） |
| 学校/机构 | 采购决策者 | 数据私有、批量账号、阅卷闭环 | ★★★★★（B 端合同） |

### 1.3 业务目标与北极星指标
- 北极星指标：**月度"有效组卷数"**（被下载/打印/布置的试卷数）。
- 辅助：题库结构化率（公式+图形非图片占比 ≥95%）、教师次月留存 ≥45%、付费转化 ≥6%、下载任务成功率 ≥99.9%。

## 2. 产品架构（功能地图）

```
智卷云
├── 教师工作台（Web，主战场）
│   ├── 题库中心：选题/搜题/看题/纠错/收藏
│   ├── 组卷中心：手动选题、智能组卷、细目表、平行卷、AI组卷
│   ├── 试卷工作台：试题篮、换题、排版、导出打印
│   ├── 录题工作台：Word导入、OCR识别、图形编辑器、校对提交
│   ├── 校本空间：校本题库、备课组协作、组内共享
│   └── AI 助手：出题/讲题/标注/审校/RAG问答
├── 学生端（APP/小程序/H5）
│   ├── 刷题练习、作业完成、错题本、AI讲题、学情报告
├── 学校版
│   ├── 校本题库资产、批量账号、作业与阅卷、考后诊断
└── 运营后台（内部）
    ├── 题目审核工作流、内容运营、会员与订单、数据看板
```

## 3. 角色与权限

| 角色 | 权限要点 |
|---|---|
| 游客 | 浏览题库列表（公式图形完整渲染）、单题详情限流、无下载 |
| 注册-教师 | 组卷、下载（按会员/点数）、录题投稿、收藏夹 |
| 注册-学生 | 练习、错题、AI 讲题（限额） |
| 备课组长 | 校本题库管理、组员共享卷审核 |
| 学校管理员 | 批量账号、校本数据看板 |
| 学科编辑（内部） | 题目审核工作流、题源管理 |
| 运营/管理员 | 全后台 |

权限模型：RBAC（角色-权限点）+ 数据权限（题目可见域：公开/校本/私有），参考 yudao-cloud 的 RBAC 实现。

## 4. 功能需求（P0=首发必须，P1=三个月内，P2=规划）

### 4.1 题库中心（P0）
- **多维筛选**：学科 → 教材版本（人教A版2019 等）→ 章节树；知识点树（3 级：领域→考点→子考点，数学含"考法/解题方法"层）；题型（选择/填空/解答/判断…按学科可配）；难度五级（易/较易/中/较难/难）；来源（高考真题【年份+地区】/模拟/名校月考/原创）；题源标签。
- **题目详情**：题干、选项（选择题）、答案、解析（多解法）、点拨/易错点、知识点标签、难度、来源、使用统计（组卷次数/正确率）、同类题推荐、纠错入口。**全部内容结构化渲染（LaTeX/SVG），支持全题检索。**
- **搜索**：关键词全文检索（ES）、筛选项组合、拍照搜题（P1，学生端）。
- 收藏夹/试题篮（上限 100 题，多端同步）。

### 4.2 组卷中心（P0）
| 组卷方式 | 说明 | 优先级 |
|---|---|---|
| 手动选题 | 筛选→加篮→进工作台 | P0 |
| 智能组卷 | 蓝图：范围+题型数量+难度分布+知识点覆盖+地区偏好+重复率控制→生成 3 套候选 | P0 |
| 真题组卷 | 按年份/地区/科目整卷或抽题 | P0 |
| 细目表组卷 | 双向细目表（知识点×题型×难度）逐格选/生成 | P1 |
| 平行卷 | A/B 卷同蓝图不同题，难度对齐 | P1 |
| AI 组卷 | 自然语言描述考试要求→AI 生成蓝图与试卷 | P1 |

- **试卷工作台**：增删换题（一键换题=同知识点+同题型+同难度+不重复）、调整分值与顺序（按题型/难度自动重排）、插入作答区、设置卷头（标题/副标题/考试信息/密封线）、保存版本历史。
- **导出（P0，核心体验）**：A4/A3、单/双栏、答案与解析分离位置（卷尾/单独文档/教师版内嵌）、Word（公式转可编辑 OMML）与 PDF、答题卡自动生成、300dpi 图形、签名 URL 下载、异步任务+完成通知。

### 4.3 数学图形与公式（P0，详见 06 文档，2026-09-28 策略修订）
- 公式：LaTeX 存储，KaTeX/MathJax 渲染；公式编辑器（MathLive）内嵌于录题与搜索。
- 图形（主渠道=截图上传，与组卷网录入方式一致）：上传即自动清洗为**纯白底、统一线色 #333、去水印、双 DPI（展示 2x / 打印 300dpi）**；展示端白底统一规范+悬停放大镜。
- 渐进数字化（P2 可选）：Figure DSL（JSON）→ 矢量 SVG；几何画板、函数绘图器、模板库；函数图可自动反解为 DSL。
- 校验：图片清洗质量抽检（白底/线色/DPI 合规率）、公式 OCR 人工确认、渲染预览三端一致性。

### 4.4 录题与题源建设（P1）
- Word 试卷导入（解析样式→结构化题目，公式 OMML→LaTeX 自动转换）。
- 图片/PDF 试卷导入：OCR 文字+公式识别（Mathpix/开源 pix2tex）+ 版面分析切题。
- 教师投稿录题（带收益分成/积分），学科编辑三审工作流（机审→一审→终审）。
- 题源合规档案：来源登记、授权链、AI 生成标识。

### 4.5 AI 功能（差异化核心）
| 功能 | 说明 | 优先级 |
|---|---|---|
| AI 组卷 | 自然语言→蓝图→生成试卷草稿（可人工调整），约束满足+LLM 双引擎 | P1 |
| AI 出题/变式 | 给定题目或考点生成同型变式题、相似题（防重复约束+查重） | P1 |
| AI 解析与审校 | 为新题生成解析草稿；对存量题做答案正确性/表述一致性机审 | P1 |
| AI 讲题 | 分步讲解（SSE 流式），苏格拉底式追问，支持图形步骤演示 | P1 |
| AI 知识点标注 | 新题自动打知识点/难度/考法标签，人工确认 | P0（内部） |
| 拍照搜题 | 手写印刷体+公式识别→向量+文本混合检索 | P1 |
| RAG 题库问答 | "帮我找 5 道导数压轴题"类自然语言检索，引用题目卡片 | P2 |
| AI 学情报告 | 班级/个人知识点掌握热力图、薄弱点推题 | P2 |

AI 治理：所有 AI 生成内容打标"AIGC"，先草稿后人工确认；教育类内容安全审核；token 配额与成本看板。

### 4.6 学生端（P1）
练习（章节/考点/真题模式）、作业（教师布置）、错题本（自动归因到知识点+相似题再练）、学情报告、AI 讲题。

### 4.7 会员与商业化（P0）
- 免费档：每日 3 次下载、组卷不限、公式图形完整渲染（诚意获客，区别于组卷网）。
- 个人会员：教师版 ¥299/年（下载不限量+AI 配额）；学生版 ¥199/年。
- 点数：按卷付费（10 题 1 点起），会员 5 折。
- 学校版：按校授权（校本题库+批量账号+阅卷）， ¥2万-8万/年/校 区间。
- 支付：微信/支付宝、对公转账（B 端）、开票流程。

### 4.8 运营后台（P0 内部）
题目审核工作流、题源管理、错题纠错处理、会员订单、优惠券（参考天机学堂促销模块）、内容运营位、数据看板（DAU/组卷量/题库增长/AI 成本）。

## 5. 非功能需求

| 类别 | 指标 |
|---|---|
| 容量 | 注册用户 3000 万+，DAU 100万（峰值 350 万），题目 2000 万条起步 |
| 性能 | 列表页 P95 < 300ms；搜索 P99 < 1s；题目详情缓存命中 P99 < 80ms；智能组卷生成 < 8s；导出任务 < 30s（20 题卷） |

| 合规 | 个保法（未成年人信息最小化）、AIGC 标识、题库版权档案 |
| 兼容 | Chrome/Edge/Safari 近两年版本；微信小程序；1080p 打印精度 |

## 6. 关键用户旅程（验收主线）
1. 教师登录 → 筛"人教A版/导数/解答题/难" → 看题（公式清晰、图形矢量）→ 加篮 → 智能组卷补齐 → 工作台微调换题 → 导出 A4 双栏 PDF+Word → 打印。
2. 教师上传扫描卷 → OCR 识别 → 图形编辑器修图 → 提交审核 → 上架（贡献积分）。
3. 学生做教师布置作业 → 自动批改（客观题）→ 错题本 → AI 讲题 → 相似题再练。

## 8. 功能全量对齐组卷网（2026-09-28 实站走查后修订）
依据《09-组卷网全量功能清单与复刻方案》，以下功能纳入复刻范围（P0/P1 见 09 文档逐条标注）：
- **选题四通道**：章节选题 / 知识点选题（含**解题方法**视角）/ 试卷选题（整卷浏览+抽题汇编）/ 智能组卷（章节版+知识点版）。
- **场景体系**：预习/课堂/作业/单元测试/阶段检测/寒暑假/一轮/二轮/三轮/高考/学业考试/特殊招生——贯穿题目筛选与智能组卷"出题场景"。
- **题目分类学**：典型题/压轴题/同步题/新文化/探究题/劣构题/开放题/新定义/课本原题。
- **题目标签体系**：难度系数(0~1) + 核心素养（数学建模能力/逻辑推理能力/数学运算能力/数学抽象能力）+ 名校标 + 解题方法标 + "只看新题"。
- **卡片元信息**：日期 | N次组卷 | N卷引用（来源卷可跳转）+ 相似题/纠错/详情/收藏/加入试题篮。
- **上好课**：按节成套资源（课前预习/课堂例题/随堂检测/课后作业·基础巩固提升三档/单元测试 A/B 卷）。
- **高考专区**：倒计时、真题按年份×卷种（全国一二卷/北京/天津/上海春秋考…）、最新模拟卷（一模/二模）、母题题源/真题分类汇编/高频考点/热点新题。
- **名校卷**：百强名校/省级重点标签 + 名校专区 + 学校订阅。
- **精品专辑**：类型×场景双维筛选 + 品牌专栏（系列化内容）+ 浏览/更新数据。
- **个人题库**：我的试题/试卷/专辑，知识点/章节/自定义三种组织，批量操作，录题工作台入口。
- **我的与激励**：积分奖励/我的存档/我的下载、消息中心、考试月历与备考日历、地区定位、限时免费/新人礼包/邀请有礼运营位。
- **试题篮与组卷中心**：上限分级（免费 50 题/会员 100 题，优于组卷网免费 35 题）、换题/分值/作答区/排序/试卷结构/全套下载参数。
- **会员体系**：免费档诚意（下载 3 次/日+教师认证加赠）、个人会员、单科会员、学校版；权益量化表对标 /membership 实测数据（见 09 文档 §2.12）。
