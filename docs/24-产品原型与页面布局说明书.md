# 产品原型与页面布局说明书 —— 智卷云（前端开发契约）

> 版本：v1.0 ｜ 2026-09-28 ｜ 上游：docs/02（PRD 功能地图）、docs/09/10（竞品页面走查）、docs/17（接口字典）、docs/21（UI 令牌与组件）
> **用途**：本文档是前端（codex / 人工）的**页面布局契约**——规定每个页面有什么区块、区块顺序、每个功能的位置与交互状态、按钮语义色。接口一律以 docs/17 为准，禁止前端自行约定字段。
> **分工边界**：布局/信息架构/交互状态/接口联调由本文档+前端实现；**视觉精修（配色方案定稿、插画/图标、字体授权、动效细节）由产品负责人完成**，见 §9 交接清单。

**登录态约定（统一）**：token 存 `localStorage.zj_token`（vip.html 登录门写入）；各页读取，401 时提示并跳转 vip.html。**禁止**在 URL/GET 参数传 token。

## 3. 会员中心 vip.html（已实现，作为交互基准）

```
[登录门]（无 token）：品牌卡=标题+演示账号说明+手机号/密码输入+登录按钮
                    +注册区（手机号+邀请码→一键注册，提示"7日会员+10点"）
[权益状态条 me-bar]：👑会员徽章(金渐变)·剩N天 ｜ 点数余额 ｜ 免费下载 x/3 ｜ 未用券 N ｜ 退出
[三档会员卡 vip-tiers]：FREE不可售不展示 / STUDENT / TEACHER_PRO(hot金边) / SINGLE
   每卡：名称+¥价格/天数+权益列表+「立即开通」→ 收银台
[点数充值 pkg-grid]：4 套餐卡（到账N点·含赠X）+「¥xx 充值」→ 收银台
[优惠券中心]：tab(可领取｜我的优惠券)
   可领取票券：左色块(满减金/折扣蓝/点数券绿)+右信息(限量·已领·每人限领·有效期·范围)
              +领取按钮（态：立即领取/已领完/已达限领/未开始/已结束）
   我的票券：同布局+右上状态角标(未使用/锁定中/已使用/已过期/已作废)，非UNUSED整卡置灰
[我的订单表]：订单号(等宽)/商品/原价/实付(券抵标注)/状态徽章/时间/操作(待支付→关闭订单)
[签到卡]：连续N天提示+当月日历30格(已签=主色白字)+「今日签到」按钮
[邀请卡]：邀请码大字+复制按钮+已邀N人·得N点+最近记录(手机号脱敏)
[点数明细表]：类型/变动(+绿-红)/余额(balance_after)/说明/时间
```
交互状态：每区必须有 加载中/空态(引导文案)/错误 Toast 三态；收银台弹层见 docs/21 §3.2。

## 8. 按钮语义色对照（实现必须遵守）

| 语义 | 类名/色值 | 出现位置 |
|---|---|---|
| 主行动 | `btn-primary` #2563EB | 登录/立即开通(非热卖)/提交纠错/生成组卷/发布 |
| 会员/付费行动 | `btn-grad` 金渐变 #B8860B→#D4A017 | TEACHER_PRO 开通、点数充值、提交导出 |
| 次要 | `btn-ghost` 描边灰 | 取消/复制/换题/收藏/查看更多 |
| 危险 | `btn-ghost` + color #DC2626 | 退款/驳回/作废/关单（一律需 confirm） |
| 禁用 | opacity .5 + not-allowed | 已领完券/已签到/配额用尽 |
| 点数增减文本 | #059669 / #DC2626 | 流水、判价提示 |

## 10. 联调验收清单（前端自测门禁）

| # | 场景 | 通过标准 |
|---|---|---|
| V-1 | 所有 API 调用 | 路径/字段与 docs/17 完全一致（抽查 diff） |
| V-2 | 登录态 | 无 token 页面可浏览，写操作 401 → 统一引导 vip.html |
| V-3 | 错误处理 | 每个 fetch 有 catch；422/429 展示服务端 message 与 data 提示（needPoints/needCents/reason） |

| V-6 | 空态三态 | 列表区均有 加载/空/错误 态 |
| V-7 | 移动端 | <768px 单列不横向滚动 |
| V-8 | KaTeX | 题干/解析 `\(..\)` 渲染，断网降级显示源码不破版 |
