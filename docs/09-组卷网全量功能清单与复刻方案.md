## 3. 图形策略调整（用户决策：截图上传为主）

**结论：与组卷网一致，题目图形以截图/图片上传为主渠道**；我们的胜出点不在"强行矢量重画"，而在**图片质量与一致性治理**：

1. **上传即清洗（自动）**：裁白边→纠偏→增强对比→**统一白底 (纯白 RGB 255)** → **统一线条颜色（深灰 #333 统一，替代扫描杂色）**→ 去水印（修复式擦除 zujuan 等来源水印）→ 统一缩放与 DPI（打印 300dpi）。
2. **展示规范**：题目卡与详情页图形统一白底、等比缩放、悬停放大镜（组卷网没有的体验）；列表懒加载 + 固定占位防抖动。
3. **渐进数字化（可选，不强求）**：函数图类自动反解表达式生成 Figure DSL；几何图教师可用画板重画后替换——替换后获得矢量/可变色/可标注能力，但不作为上架门槛。
4. **录题流水线**：整卷扫描→版面切题→公式 OCR 转 LaTeX（正文必须数字化，这是和组卷网一样用图片的关键区别：**图形用图、文字与公式必须结构化**）→ 图形单独切出走清洗管线 → 三审上架。

> 由此修订 06 文档：Figure DSL 与几何画板降级为 P2 增强项；**图片清洗管线升级为 P0**。
