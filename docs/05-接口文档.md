# 接口文档 —— 智卷云 API v1

> 版本：v1.0 ｜ Base URL：`https://api.examforge.example.com/api/v1` ｜ 认证：`Authorization: Bearer <JWT>`
> 联调工具：Knife4j（后端 springdoc 自动生成，与本文档同源维护）

## 1. 全局约定

- 响应体统一：
```json
{ "code": 0, "message": "ok", "data": { }, "traceId": "a1b2c3" }
```
- 分页：`?pageNo=1&pageSize=20`，响应 `data: { list: [], total: 1234 }`；pageSize 上限 50。
- 幂等：写操作（下单/导出/组卷生成）必须携带 `X-Idempotency-Key`（UUID），重复请求返回首次结果。
- 限流：响应头 `X-RateLimit-Remaining`；触发限流返回 `429` + code `14029`。
- **服务端外呼安全约束（SSRF，验收硬指标）**：任何服务端根据用户输入发起的 URL 抓取（图片代理、回调、webhook）仅允许 https + 域名白名单 + 解析 IP 非内网/环回/链路本地段，DNS 重绑定二次校验。

### 错误码（节选）
| code | HTTP | 含义 |
|---|---|---|
| 0 | 200 | 成功 |
| 40100 | 401 | 未登录/Token 过期 |
| 40301 | 403 | 无权限（如下载超限） |
| 40400 | 404 | 资源不存在 |
| 42200 | 422 | 参数校验失败（data 返回字段级错误） |
| 42900 | 429 | 触发限流/配额不足 |
| 50010 | 500 | 系统错误 |
| 50201 | 502 | 下游 AI 服务不可用（自动降级提示） |
| 60010 | 200 | 任务排队中（异步任务语义） |

              &difficulty=4,5&sourceType=1&year=2025&region=11
              &keyword=双曲线&sort=hot&pageNo=1&pageSize=20
→ data: { total: 1284, list: [ {
    "id": 900000123456, "questionType": 4, "difficulty": 5,
    "source": { "type": "GAOKAO", "year": 2025, "region": "新高考Ⅰ卷" },
    "knowledgePoints": [ {"id":88,"name":"导数的应用"}, {"id":89,"name":"极值与最值"} ],
    "stats": { "composeCount": 12456, "correctRate": 0.42 },

## 4. 组卷

### 4.1 创建蓝图（智能组卷）
```
POST /paper-blueprints
{ "subjectId": 2, "name": "高二上期中模拟",
  "scope": { "catalogIds": [302,303], "kpIds": [88,89,90] },
  "structure": [ {"type":1,"count":8,"score":5}, {"type":3,"count":4,"score":5}, {"type":4,"count":5,"score":12} ],
  "difficultyDist": { "1":0.1, "2":0.3, "3":0.35, "4":0.2, "5":0.05 },
  "kpCoverage": [88,89,90], "preferRegion": "全国卷", "dupControl": { "excludeMineDays": 30 } }
→ data: { "blueprintId": 770001 }
```

### 4.2 智能生成（异步）
```
POST /papers/generate   { "blueprintId": 770001, "candidates": 3 }   // X-Idempotency-Key 必填
→ data: { "taskId": "gen_20260928_000123" }                        // code=60010 语义
GET  /tasks/{taskId}    → { "status": "RUNNING|DONE|FAILED", "progress": 60,
                            "resultPaperIds": [880001,880002,880003],
                            "report": { "kpCoverageRate": 1.0, "difficultyFit": 0.93 } }
```

### 4.3 试卷编辑
```
GET   /papers/{id}                    → 卷结构(sections+questions, 全预渲染HTML)
POST  /papers/{id}/replace-question   { "questionId": 900…, "strategy": "SAME_KP_SAME_TYPE_SAME_DIFF" }
→ data: { "newQuestion": { …同构新题… } }              // 一键换题
PUT   /papers/{id}/sections/{sid}/order     { "questionIds": [...] }
PUT   /papers/{id}/meta               { "title": "2026-2027学年度第一学期期中考试", "showSealLine": true }
```

### 4.4 导出（异步+签名下载）
```
POST /papers/{id}/export   { "format": "PDF", "options": { "paper": "A4", "columns": 2,
                             "answerPosition": "SEPARATE", "dpi": 300, "fontSize": "M" } }
→ data: { "taskId": "exp_…", "deductPoints": 0 }      // 免费额度内为0
GET  /tasks/{taskId}        → { "status": "DONE", "fileUrl": "https://oss…/exp.pdf?sig=…&exp=1727…" }
```
> `fileUrl` 为 5 分钟有效签名 URL；Word 版公式转 OMML 可编辑。

## 6. AI

```
POST /ai/compose-paper    { "prompt": "高二立体几何期中卷，8选择4填空3解答，中档为主，含一道空间向量压轴",
                            "blueprintId": 770001 }          // AI生成蓝图可回填人工确认
→ data: { "taskId": "ai_…" }
POST /ai/generate-question { "questionId": 900000123456, "variant": "SAME_TYPE",
                             "count": 3 }                     // 变式题(草稿态,须审核)
POST /ai/explain           { "questionId": 900000123456, "mode": "SOCRATIC" }  // SSE 流式
→ text/event-stream: data: {"step":1,"text":"先看定义域…","latex":"x>0"} … data: {"done":true,"quotaLeft":42}
POST /ai/search-by-image   (multipart: file)                    // 拍照搜题,OCR+向量混合
→ data: { "recognizedLatex": "\\frac{x^2}{4}-y^2=1", "candidates": [ {questionId, score} ] }
```
> AI 接口全部记账（用户/功能/token），免费用户有日配额，超额返回 42900。

## 9. 接口安全验收清单
1. 所有列表/详情接口登录态与游客态差异化（游客限流 30 次/时）。
2. 下载与导出：签名 URL、点数/会员校验在**服务端**完成、水印 ID 注入。
3. 上传：类型白名单、大小限制、病毒扫描、图片走 media-svc 预处理。
4. 外呼 SSRF 校验（见第 1 节）；支付回调验签+来源 IP 白名单。
5. 全接口审计日志（谁在何时导出了哪份卷，含题目 ID 列表——版权追溯用）。
