# 部署指南（目标：07:00 前完成部署）

## 一、本机部署（Windows，最简）
```bat
cd E:\code\business\zujuan-platform\code\app
npm install
npm run smoke      # 冒烟测试应输出 N 通过 / 0 失败
npm start          # 启动后访问：
```
- 前台：http://localhost:3000/prototype/index.html
- 超管后台：http://localhost:3000/admin （13000000000 / Admin@123456）
- 健康检查：http://localhost:3000/api/v1/health

## 二、Linux / 云主机部署
```bash
# 方式 A：裸机
unzip app.zip && cd app && npm install --omit=dev
PORT=3000 node server/server.js     # 建议配 pm2: npm i -g pm2 && pm2 start server/server.js --name zhijuan

# 方式 B：Docker
docker build -t zhijuan:latest .
docker run -d -p 80:3000 --name zhijuan -e JWT_SECRET=请换成强随机串 zhijuan:latest
```
- 云主机安全组放行 80/3000；域名解析后 Nginx 反代 80 → 3000（可选）。
- 生产环境务必：① 修改超管默认密码；② 设置强 JWT_SECRET；③ SQLite 数据目录纳入备份（server/data/）。
